# 🛡️ CVE Auto-Report Platform
### AI 기반 CVE 취약점 분석 및 리포트 자동화 플랫폼


---

## ■ 프로젝트 정의

CISA KEV와 NVD의 공개 데이터를 수집하여 실제 공격에 악용되는 고위험 취약점을 선별하고, Gemini LLM을 활용해 운영자 관점의 보안 리포트를 자동 생성하고 GitHub Pages에 배포하는 자동화 프로젝트입니다.


---

## ■ 주요 용어

| 용어 | 설명 |
|---|---|
| ※ CISA KEV | 미국 사이버보안국(CISA)이 관리하는, 실제 해커들이 공격에 악용 중인 '알려진 취약점(Known Exploited Vulnerabilities)' 목록 |
| ※ NVD | 미국 국립표준기술연구소(NIST)가 운영하는 국가 취약점 데이터베이스 |
| ※ CVSS | 보안 취약점의 위험도를 평가하는 국제 표준 점수 체계 (0~10점) |


---

## ■ 동작 요약

```
최신 취약점 수집 → 우선순위 산정 → AI 심층 분석 → Markdown 생성 → HTML 변환 → 웹 배포
```

- 전 과정을 자동화하여 보안 담당자의 리서치 시간을 단축하는 것을 목표로 개발하였습니다.


---

## ■ 주요 기능

- ✅ AI 심층 분석 : Gemini 2.5 Flash 모델을 활용해 '공격 영향도'와 '운영자 체크리스트' 중심의 실무 친화적 리포트 생성

- ✅ 위험도 기준 분류 : 수많은 CVE 중 CVSS 7.0 이상의 고위험 취약점만 필터링하고 최신성 순으로 Top 5를 자동 선정

- ✅ 무중단 설계 : AI API 한도 등으로 호출이 실패하면 수집한 원본 데이터를 기반으로 기본 리포트를 생성하여 파이프라인이 중단되지 않도록 설계

- ✅ 자동화 : GitHub Actions 스케줄러를 통해 매일 자동으로 파이프라인이 실행

## ■ 파일 구조 트리

```text
cve_platform/
├── .github/
│   └── workflows/
│       └── weekly-pipeline.yml       # 매일 자정 리포트를 자동 생성/배포하는 스크립트
├── content/                          # 파이프라인을 통해 생성된 원본 리포트 저장소
│   ├── report_YYYY-MM-DD.md          # 마크다운 원본 리포트
│   └── report_YYYY-MM-DD.html        # HTML 변환 리포트
├── docs/                             # GitHub Pages 퍼블리싱용 정적 웹 디렉터리
│   ├── reports/                      # 배포용 HTML 리포트 아카이브
│   └── index.html                    # 월별 추이 차트 및 리포트 목록을 보여주는 대시보드
├── src/
│   └── cve_platform/                 # 핵심 비즈니스 로직 (소스코드)
│       ├── collectors/               # 1. 데이터 수집 모듈
│       │   ├── cisa_kev.py           # CISA KEV 피드 파싱
│       │   └── nvd_cvss.py           # NVD API 호출 (CVSS/CPE 조회)
│       ├── processors/               # 2. 취약점 선별 모듈
│       │   ├── filter.py             # CVSS 7.0 이상 필터링
│       │   └── ranker.py             # 최신성 및 위험도 기반 Top 5 정렬
│       ├── analyzers/                # 3. AI 분석 모듈
│       │   ├── gemini_provider.py    # Gemini 2.5 Flash 기반 심층 분석 (Retry 포함)
│       │   └── claude_provider.py    # AI 장애 시 원본 데이터로 우회(Fallback)하는 대체 로직
│       ├── generators/               # 4. 리포트 생성
│       │   ├── markdown_generator.py # 분석 결과를 마크다운 양식으로 생성
│       │   └── html_generator.py     # 마크다운을 Pretendard 테마의 HTML로 변환
│       ├── publishers/               # 5. 웹 배포 모듈
│       │   └── github_pages.py       # docs 디렉터리에 파일 저장 및 index.html 자동 갱신
│       ├── main.py                   # 전체 파이프라인(수집→분석→배포)을 관장하는 실행 스크립트
│       ├── models.py                 # Pydantic을 활용한 API 응답 및 AI 출력 스키마 정의
│       └── utils.py                  # 공통 유틸리티 함수 모음
├── .env.example                      # API 키 환경 변수 템플릿
├── prompt.md                         # AI 심층 분석을 위한 프롬프트 가이드라인
├── pyproject.toml                    # 패키지 메타데이터 및 의존성(라이브러리) 관리 파일
└── README.md                         # 프로젝트 소개 및 가이드 문서
```
