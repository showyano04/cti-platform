## 1. CVE-2026-16812 — Arista VeloCloud Orchestrator On-Prem OS Command Injection Vulnerability

- **CVSS**: 10.0 (CRITICAL)
- **KEV 등재**: 예 (등재일 2026-07-27, 패치 기한 2026-07-30)
- **영향 제품**: Arista VeloCloud Orchestrator
- **영향 버전(NVD 기준)**: Arista VeloCloud Orchestrator 5.2.0 이상 5.2.3.14 미만, 6.1.0 이상 6.1.3.4 미만, 6.4.0 이상 6.4.2.4 미만, 7.0.0 버전
- **랜섬웨어 연관**: Unknown

**개요**: Arista VeloCloud Orchestrator On-Prem 제품에서 발견된 운영체제 명령어 삽입(검증되지 않은 입력 값을 통해 시스템 명령어를 강제로 실행하는 취약점) 취약점입니다. 원격의 공격자가 이를 악용해 특권 내부 기능에 접근하고 시스템 제어권을 확보할 수 있습니다.

**공격 영향**: 원격 공격자가 권한이 필요한 내부 기능에 접근하여 오케스트레이터(여러 IT 자원을 자동으로 통합 관리하는 시스템) 호스트의 제어권을 취득할 수 있습니다. 이로 인해 시스템 및 관리 중인 전체 데이터의 기밀성, 완전성, 가용성이 심각하게 침해될 수 있습니다.

**패치 우선순위**: CVSS 점수가 10.0(치명적)으로 매우 높고 패치 기한이 2026-07-30까지로 지정되어 있어 최우선 패치 적용이 필요합니다. 랜섬웨어 연관 여부는 제공된 데이터에 명시되지 않았으나 원격 공격 위험도가 매우 높으므로 즉시 제조사 지침에 따라 패치하거나 보안 완화 조치를 적용해야 합니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- Arista VeloCloud Orchestrator 제품의 현재 설치 버전을 확인하여 취약 대상 버전인지 점검
- 제조사 공식 안내에 따라 즉시 최신 보안 패치 적용
- 오케스트레이터 자원의 인터넷 노출 상태를 평가하고 불필요한 원격 접근 차단
- CISA BOD 26-04 지침 및 사고 분석 요구사항에 따른 보안 조치 이행
- 즉각적인 패치가 불가능한 경우 완화 조치 적용 또는 서비스 사용 일시 중단 검토

**참고 자료**: https://www.arista.com/en/support/advisories-notices/security-advisory/24364-security-advisory-0144, https://www.cisa.gov/news-events/directives/bod-26-04-prioritizing-security-updates-based-risk, https://www.cisa.gov/news-events/directives/bod-26-04-implementation-guidance-prioritizing-security-updates-based-risk, https://nvd.nist.gov/vuln/detail/CVE-2026-16812

## 2. CVE-2026-50522 — Microsoft SharePoint Deserialization of Untrusted Data Vulnerability 

- **CVSS**: 9.8 (CRITICAL)
- **KEV 등재**: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
- **영향 제품**: Microsoft SharePoint
- **영향 버전(NVD 기준)**: Microsoft SharePoint Server 16.0.19725.20434 미만 버전, Microsoft SharePoint Server 2016, Microsoft SharePoint Server 2019
- **랜섬웨어 연관**: Unknown

**개요**: Microsoft SharePoint에서 신뢰할 수 없는 데이터의 역직렬화(외부에서 들어온 검증되지 않은 데이터를 프로그램이 사용하는 객체로 복원하는 과정) 취약점이 발생했습니다. 인증되지 않은 공격자가 네트워크를 통해 대상 시스템에서 임의의 코드를 실행할 수 있습니다.

**공격 영향**: 권한이 없는 공격자가 네트워크를 통해 신뢰할 수 없는 데이터를 전송하고 이를 역직렬화하도록 유도함으로써 원격으로 임의 코드를 실행하고 시스템을 제어할 수 있습니다.

**패치 우선순위**: CVSS 점수가 9.8점으로 심각 등급에 해당하며 패치 기한이 2026년 7월 25일로 지정되어 있어 매우 높은 우선순위로 패치를 적용해야 합니다. 랜섬웨어 연관 여부는 제공된 데이터에 명시되지 않았습니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 현재 운영 중인 Microsoft SharePoint Server가 16.0.19725.20434 미만 버전이거나 2016, 2019 버전인지 확인합니다.
- 공급업체의 안내에 따라 보안 업데이트 및 완화 조치를 즉시 적용합니다.
- 인터넷에 노출되어 있는 SharePoint 자산 현황을 평가합니다.
- CISA의 포렌식 트리아지(취약점 노출 및 공격 여부를 신속히 침해조사하는 과정) 요구사항 및 보안 업데이트 지침 준수 여부를 점검합니다.

## 4. CVE-2026-63030 — WordPress Core Interpretation Conflict Vulnerability

- **CVSS**: 9.8 (CRITICAL)
- **KEV 등재**: 예 (등재일 2026-07-21, 패치 기한 2026-07-24)
- **영향 제품**: WordPress Core
- **영향 버전(NVD 기준)**: 워드프레스 6.9 이상 6.9.5 미만, 워드프레스 7.0 이상 7.0.2 미만
- **랜섬웨어 연관**: Unknown

**개요**: 워드프레스 코어에서 해석 충돌 취약점이 발생하여 공격자가 데이터베이스 구문을 무단 주입하는 SQL Injection을 수행하고, 나아가 시스템 제어권을 확보하는 RCE까지 달성할 수 있습니다. 이 취약점은 CVE-2026-60137 취약점과 연쇄적으로 결합되어 공격에 악용될 수 있습니다.

**공격 영향**: 공격자가 해당 취약점을 악용할 경우 데이터베이스의 정보를 무단 조회·수정할 수 있는 SQL Injection 피해를 입을 수 있으며, 이를 바탕으로 웹 서버에서 악의적인 명령을 직접 실행하는 RCE까지 가능해져 서버 전체가 탈취될 수 있습니다.

**패치 우선순위**: 최우선 적용(CVSS 점수가 9.8로 치명적인 수준이며, SQL Injection 및 RCE 공격으로 이어져 서버 제어권을 상실할 수 있고 연쇄 공격 가능성이 존재하므로 지침에 따라 2026년 7월 24일까지 패치를 완료해야 합니다)

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 사용 중인 워드프레스 코어 버전을 확인하여 6.9~6.9.4 및 7.0~7.0.1 범위에 해당하는지 점검합니다.
- 워드프레스 공식 안내에 따라 취약점이 수정된 최신 버전으로 즉시 업데이트를 수행합니다.
- 연쇄 공격에 악용될 수 있는 CVE-2026-60137 취약점의 조치 여부도 함께 확인합니다.
- 인터넷에 직접 노출된 워드프레스 자산 목록을 식별하고 CISA BOD 26-04 패치 가이드라인 준수 상태를 점검합니다.
- 웹 서버 및 데이터베이스 요청 로그를 분석하여 비정상적인 해석 충돌 또는 무단 데이터베이스 접근 시도가 있었는지 침해 조사를 실시합니다.

**참고 자료**: https://wordpress.org/news/2026/07/wordpress-7-0-2-release/, https://www.cisa.gov/news-events/directives/bod-26-04-prioritizing-security-updates-based-risk, https://www.cisa.gov/news-events/directives/bod-26-04-implementation-guidance-prioritizing-security-updates-based-risk, https://nvd.nist.gov/vuln/detail/CVE-2026-63030
