# 주간 주요 취약점(CVE) 분석 리포트 — 2026-08-03

## 1. CVE-2026-16812 — Arista VeloCloud Orchestrator On-Prem OS Command Injection Vulnerability

- **CVSS**: 10.0 (CRITICAL)
- **KEV 등재**: 예 (등재일 2026-07-27, 패치 기한 2026-07-30)
- **영향 제품**: Arista VeloCloud Orchestrator
- **영향 버전(NVD 기준)**: Arista VeloCloud Orchestrator On-Prem 제품 중 다음 버전에 영향을 미칩니다: 5.2.0 이상 5.2.3.14 미만, 6.1.0 이상 6.1.3.4 미만, 6.4.0 이상 6.4.2.4 미만, 그리고 7.0.0 버전.
- **랜섬웨어 연관**: Unknown

**개요**: CVE-2026-16812은 Arista VeloCloud Orchestrator On-Prem 제품에서 발생하는 OS 명령 주입(운영체제 명령어 삽입) 취약점입니다. 이 취약점을 악용하면 원격 공격자가 권한이 있는 내부 기능에 접근하여 Arista VeloCloud Orchestrator 호스트 시스템에 영향을 미칠 수 있습니다.

**공격 영향**: 공격자가 이 취약점을 성공적으로 악용하면 Arista VeloCloud Orchestrator 시스템에 대해 OS 명령 주입 공격을 수행할 수 있습니다. 이는 시스템의 기밀성(민감 정보가 노출될 수 있음), 무결성(데이터나 시스템 구성이 변경될 수 있음), 가용성(서비스가 중단될 수 있음)을 심각하게 손상시켜, 오케스트레이터와 오케스트레이터가 관리하는 데이터에 광범위한 영향을 줄 수 있습니다.

**패치 우선순위**: CVSS 점수 10.0으로 'CRITICAL' 등급이며, CISA(미국 사이버 보안 및 인프라 보안국)에서 완화 조치 적용을 권고하고 2026년 7월 30일까지의 패치 기한을 명시했습니다. 이는 최우선으로 즉시 패치 또는 완화 조치 적용이 필요한 매우 심각한 취약점입니다. KEV(Known Exploited Vulnerabilities) 등재 여부와 랜섬웨어 연관 여부는 제공된 데이터에 명시되지 않았습니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 모든 Arista VeloCloud Orchestrator On-Prem 시스템이 벤더 지침에 따라 최신 패치 또는 완화 조치를 적용했는지 즉시 확인합니다.
- CISA의 BOD 26-04(위험 기반 보안 업데이트 우선순위 지정) 지침을 준수하여 보안 업데이트 및 완화 조치를 적용합니다.
- 클라우드 서비스를 사용하는 경우, 해당 BOD 26-04 지침을 따르고, 만약 완화 조치가 불가능하다면 제품 사용 중단을 고려합니다.
- 조직 내 모든 자산의 인터넷 노출 여부를 평가하고, BOD 26-04 패치 가이드라인을 준수하는지 확인합니다.

## 2. CVE-2026-50522 — Microsoft SharePoint Deserialization of Untrusted Data Vulnerability 

- **CVSS**: 9.8 (CRITICAL)
- **KEV 등재**: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
- **영향 제품**: Microsoft SharePoint
- **영향 버전(NVD 기준)**: Microsoft SharePoint Server 중 버전 16.0.19725.20434 미만에 해당하는 제품(버전 정보 없음), Microsoft SharePoint Server 2016, 그리고 Microsoft SharePoint Server 2019가 이 취약점의 영향을 받습니다.
- **랜섬웨어 연관**: Unknown

**개요**: CVE-2026-50522은 Microsoft SharePoint에서 발견된 역직렬화(외부에서 받은 데이터를 프로그램이 다룰 수 있는 형태로 복원하는 과정) 취약점입니다. 이 취약점을 이용하면 무단 공격자가 네트워크를 통해 원격으로 코드를 실행할 수 있습니다.

**공격 영향**: 공격자는 이 취약점을 악용하여 특별히 조작된 데이터를 영향받는 SharePoint 서버로 전송할 수 있습니다. 서버가 이 데이터를 역직렬화하는 과정에서 적절한 검증 없이 처리하게 되면, 공격자의 악성 코드가 서버에서 실행될 수 있습니다. 이는 공격자가 해당 SharePoint 서버에 대한 완전한 제어권을 획득하거나, 서버 내 중요한 데이터를 탈취하고, 나아가 내부 네트워크로 침투할 수 있는 심각한 결과를 초래할 수 있습니다.

**패치 우선순위**: 이 취약점은 CVSS 점수 9.8(CRITICAL)로 매우 심각한 수준이며, CISA가 2026년 7월 25일까지 패치 기한을 지정한 KEV(Known Exploited Vulnerabilities) 목록에는 등재되지 않았습니다(제공된 데이터에 명시되지 않음). 랜섬웨어와의 연관성도 현재 알 수 없습니다. 그러나 심각한 원격 코드 실행(RCE) 가능성과 CISA의 긴급 권고에 따라, 이 취약점은 최우선으로 패치해야 할 위협으로 분류됩니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 영향받는 SharePoint 서버에 대해 벤더사 지침에 따라 제공되는 완화 조치 또는 보안 업데이트를 즉시 적용합니다.
- CISA BOD 26-04(위험 기반 보안 업데이트 우선순위 지정) 지침을 준수하여 업데이트 우선순위를 지정하고 적용합니다.
- CISA의 '포렌식 트리아지 요구사항'을 준수하여 잠재적 침해 발생 시 신속한 대응을 준비합니다.
- 클라우드 서비스의 경우 관련 BOD 26-04 지침을 따르고, 완화 조치가 없는 경우 제품 사용 중단을 고려합니다.
- 영향받는 SharePoint 서버의 인터넷 노출 여부를 평가하고, BOD 26-04 패치 지침 준수 여부를 확인합니다.
- 시스템 취약점 스캔을 수행하여 패치 적용 여부를 주기적으로 확인하고 관리합니다.
- 네트워크 경계에서 SharePoint 서버로의 불필요한 네트워크 접근을 제한하여 공격 노출면을 줄입니다.

## 3. CVE-2026-16232 — Check Point SmartConsole Improper Authentication Vulnerability

- **CVSS**: 9.1 (CRITICAL)
- **KEV 등재**: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
- **영향 제품**: Check Point SmartConsole
- **영향 버전(NVD 기준)**: Check Point Multi-Domain Security Management r77.30 이상 r81.20 미만 버전; Check Point Multi-Domain Security Management r81.20; Check Point Multi-Domain Security Management r82; Check Point Multi-Domain Security Management r82.10; Check Point Quantum Security Management r77.30 이상 r81.20 미만 버전; Check Point Quantum Security Management r81.20; Check Point Quantum Security Management r82; Check Point Quantum Security Management r82.10 버전에 영향을 미칩니다. (NVD CPE 데이터 기준)
- **랜섬웨어 연관**: Unknown

**개요**: CVE-2026-16232는 Check Point SmartConsole에서 발견된 부적절한 인증(Improper Authentication) 취약점입니다. 이 취약점을 이용하면 원격의 인증되지 않은 공격자가 애플리케이션 로그인 토큰을 획득하여 최고 관리자 권한으로 시스템에 접근하고 인증할 수 있습니다.

**공격 영향**: 이 취약점이 성공적으로 악용될 경우, 공격자는 인증 절차를 우회하여 Check Point SmartConsole에 최고 관리자 권한으로 로그인할 수 있습니다. 이는 공격자가 보안 정책을 변경하거나, 시스템 설정을 조작하거나, 관리하는 네트워크 장비에 대한 완전한 제어권을 획득할 수 있음을 의미합니다. 결과적으로 전체 보안 인프라의 심각한 손상 또는 통제권 상실로 이어질 수 있습니다.

**패치 우선순위**: 이 취약점은 CVSS v3.1 점수 9.1점으로 매우 심각(CRITICAL)하며, CISA(미국 사이버 보안 및 인프라 보안국)에서 2026년 7월 25일까지 패치 또는 완화 조치를 권고하고 있습니다. 랜섬웨어 연관성 및 KEV(Known Exploited Vulnerabilities) 등재 여부는 제공된 데이터에 명시되지 않았습니다. 하지만 높은 CVSS 점수와 CISA의 긴급 권고에 따라 즉시 패치 및 완화 조치를 적용해야 하는 최우선순위 취약점으로 판단됩니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 현재 운영 중인 Check Point SmartConsole 인스턴스 중 영향을 받는 버전(Multi-Domain Security Management 또는 Quantum Security Management r77.30 이상 r81.20 미만, r81.20, r82, r82.10)이 있는지 즉시 확인합니다.
- 영향받는 시스템이 발견되면 Check Point의 공식 권고 사항에 따라 즉시 최신 패치 또는 완화 조치를 적용합니다.
- 외부 네트워크에 노출된 Check Point SmartConsole 인스턴스가 있는지 평가하고, 불필요하게 외부에 노출되어 있다면 접근을 제한하는 조치를 취합니다.
- 공격자가 최고 관리자 권한을 획득할 가능성을 고려하여, 시스템의 비정상적인 로그인 시도 또는 관리자 활동이 있는지 보안 로그를 면밀히 모니터링하고 감사합니다.
- 만약 벤더의 완화 조치가 즉시 불가능하거나 효과적이지 않다고 판단될 경우, CISA 권고에 따라 해당 제품의 사용 중단 또는 격리를 고려합니다.

## 4. CVE-2026-63030 — WordPress Core Interpretation Conflict Vulnerability

- **CVSS**: 9.8 (CRITICAL)
- **KEV 등재**: 예 (등재일 2026-07-21, 패치 기한 2026-07-24)
- **영향 제품**: WordPress Core
- **영향 버전(NVD 기준)**: WordPress Core 제품 중 6.9 이상 6.9.5 미만 버전, 그리고 7.0 이상 7.0.2 미만 버전이 이 취약점에 영향을 받습니다.
- **랜섬웨어 연관**: Unknown

**개요**: WordPress Core에서 해석 충돌 취약점이 발견되었습니다. 이 취약점을 이용하면 공격자가 SQL Injection(데이터베이스에 악의적인 명령을 주입하는 공격)을 수행하여 원격 코드 실행(서버에서 임의의 코드를 실행하는 공격)을 달성할 수 있습니다. 특히 이 취약점은 CVE-2026-60137과 연계되어 더 심각한 공격으로 이어질 수 있습니다.

**공격 영향**: 공격자가 이 취약점을 성공적으로 악용할 경우, 다음과 같은 심각한 피해가 발생할 수 있습니다. SQL Injection을 통해 데이터베이스에 저장된 민감한 정보(예: 사용자 계정 정보, 개인 데이터)가 유출될 수 있습니다. 또한 원격 코드 실행이 성공하면 공격자가 웹 서버의 관리 권한을 획득하여 웹사이트 변조, 악성 코드 배포, 추가적인 내부 시스템 침투 등 광범위한 피해를 일으킬 수 있습니다.

**패치 우선순위**: 이 취약점의 CVSS 점수는 9.8점으로 매우 심각(CRITICAL)하며, CISA가 권고 조치를 발표하고 2026년 7월 24일까지 패치를 요구하고 있어 즉각적인 조치가 필요합니다. 랜섬웨어 연관 여부는 현재 알 수 없지만, 높은 심각도와 CISA의 긴급 권고를 고려할 때 최우선적으로 패치를 적용해야 합니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 현재 운영 중인 WordPress Core의 버전을 확인하고, 영향받는 버전에 해당하는지 점검합니다.
- 워드프레스 관리자 대시보드 또는 FTP를 통해 설치된 WordPress Core의 버전을 정확히 확인합니다.
- 제공된 패치 기한(2026-07-24) 이전에 공급업체(워드프레스)의 지침에 따라 최신 보안 업데이트를 적용합니다.
- 즉시 업데이트가 어려운 경우, CISA가 권고하는 완화 조치를 적용하고 해당 가이드라인을 준수합니다.
- 웹 애플리케이션 방화벽(WAF) 등을 사용하여 SQL Injection 시도를 탐지하고 차단하는 규칙이 올바르게 설정되어 있는지 확인합니다.
- 모든 웹 서비스 및 서버에 대한 접근 제어 정책을 검토하고 불필요한 접근이 발생하지 않도록 조치합니다.
- 정기적으로 시스템 로그를 검토하여 비정상적인 활동이나 잠재적인 침입 시도가 없는지 모니터링합니다.

- **영향 제품**: Langflow Langflow
- **영향 버전(NVD 기준)**: langflow/langflow 1.7.3 이하 버전
