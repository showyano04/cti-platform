# 일간 주요 취약점(CVE) 분석 리포트 — 2026-08-04

## 1. CVE-2026-16812 — Arista VeloCloud Orchestrator On-Prem OS Command Injection Vulnerability

- **CVSS**: 10.0 <span class="severity-badge sev-critical">CRITICAL</span>
- **KEV 등재**: 예 (등재일 2026-07-27, 패치 기한 2026-07-30)
- **영향 제품**: Arista VeloCloud Orchestrator
- **영향 버전(NVD 기준)**: Arista VeloCloud Orchestrator의 다음 버전이 영향을 받습니다: 5.2.0 이상 5.2.3.14 미만, 6.1.0 이상 6.1.3.4 미만, 6.4.0 이상 6.4.2.4 미만, 그리고 7.0.0 버전.
- **랜섬웨어 연관**: Unknown

**개요**: CVE-2026-16812은 Arista VeloCloud Orchestrator On-Prem 제품에서 발견된 운영체제 명령 주입(OS Command Injection) 취약점입니다. 이 취약점을 이용하면 원격 공격자가 특권이 있는 내부 기능에 접근하여 VeloCloud Orchestrator(VCO) 호스트에 영향을 미칠 수 있습니다.

**공격 영향**: 공격에 성공하면 공격자는 VeloCloud Orchestrator와 오케스트레이터가 관리하는 데이터의 기밀성(데이터 유출), 무결성(데이터 변조), 가용성(서비스 중단)을 침해할 수 있습니다. 이는 시스템의 핵심 기능을 공격자가 마음대로 조작할 수 있게 하여 심각한 보안 위험을 초래합니다.

**패치 우선순위**: 이 취약점의 CVSS 점수는 10.0으로 '심각(CRITICAL)' 등급이며, CISA가 권고 조치를 발행하고 2026년 7월 30일까지 패치 기한을 명시했으므로, 최우선적으로 패치 및 완화 조치가 필요합니다. 랜섬웨어 연관성은 제공된 데이터에 명시되지 않았습니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 영향받는 VeloCloud Orchestrator On-Prem 시스템을 식별합니다.
- 공급업체의 지침에 따라 최신 보안 패치 또는 완화 조치를 즉시 적용합니다.
- CISA의 BOD 26-04(위험 기반 보안 업데이트 우선순위 지정) 지침을 준수하여 패치 우선순위를 결정하고 적용합니다.
- 시스템의 인터넷 노출 여부를 평가하고, 불필요한 노출을 최소화하기 위한 보안 설정을 검토합니다.
- 패치 적용 후 시스템이 정상적으로 작동하는지 확인하고, 잠재적인 침해 지표(Indicators of Compromise)를 모니터링합니다.

## 2. CVE-2026-50522 — Microsoft SharePoint Deserialization of Untrusted Data Vulnerability 

- **CVSS**: 9.8 <span class="severity-badge sev-critical">CRITICAL</span>
- **KEV 등재**: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
- **영향 제품**: Microsoft SharePoint
- **영향 버전(NVD 기준)**: Microsoft SharePoint Server 버전 16.0.19725.20434 미만, Microsoft SharePoint Server 2016, Microsoft SharePoint Server 2019 제품이 이 취약점에 영향을 받습니다. SharePoint Server 2016 및 2019의 상세 버전 정보는 제공되지 않았습니다.
- **랜섬웨어 연관**: Unknown

**개요**: Microsoft SharePoint 제품에서 신뢰할 수 없는 데이터의 역직렬화(외부에서 받은 데이터를 프로그램이 다룰 수 있는 형태로 복원하는 과정) 취약점(CVE-2026-50522)이 발견되었습니다. 이 취약점을 이용하면 권한 없는 공격자가 네트워크를 통해 원격으로 코드를 실행할 수 있습니다.

**공격 영향**: 이 취약점을 악용하면 권한 없는 공격자가 네트워크를 통해 영향을 받는 SharePoint 시스템에 원격 코드 실행(RCE)이 가능해집니다. 이는 공격자가 시스템에 임의의 명령을 실행하거나, 데이터를 조작하고, 서비스 운영을 방해하거나, 심지어 시스템을 완전히 장악할 수 있음을 의미합니다.

**패치 우선순위**: CVSS 점수 9.8점으로 '심각' 수준이며, 권한 없는 공격자가 원격 코드 실행(RCE)을 할 수 있어 즉각적인 조치가 필요합니다. CISA의 권고 조치가 발표되었으며, 2026년 7월 25일까지 패치를 완료해야 하므로 최우선 순위로 패치를 적용해야 합니다. 랜섬웨어 연관성은 현재 제공된 데이터에 명시되지 않았습니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 현재 운영 중인 Microsoft SharePoint 시스템의 버전을 확인합니다.
- 영향받는 버전(SharePoint Server 버전 16.0.19725.20434 미만, SharePoint Server 2016, SharePoint Server 2019)에 해당하는지 확인합니다.
- 해당하는 경우, Microsoft에서 제공하는 최신 보안 업데이트 또는 권고되는 완화 조치를 즉시 적용합니다.
- CISA의 BOD 26-04(위험 기반 보안 업데이트 우선순위 지정) 지침 및 CISA의 '포렌식 트리아지 요구사항'을 준수하여 조치를 수행합니다.
- 클라우드 서비스를 사용하는 경우, 관련 BOD 26-04 지침을 따르거나 완화 조치가 불가능하면 제품 사용을 중단하는 것을 고려합니다.
- 모든 자산의 인터넷 노출 여부를 평가하고 BOD 26-04 패치 지침 준수 여부를 확인합니다.

## 3. CVE-2026-16232 — Check Point SmartConsole Improper Authentication Vulnerability

- **CVSS**: 9.1 <span class="severity-badge sev-critical">CRITICAL</span>
- **KEV 등재**: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
- **영향 제품**: Check Point SmartConsole
- **영향 버전(NVD 기준)**: Check Point Multi-Domain Security Management r77.30 이상 r81.20 미만, r81.20, r82, r82.10 버전과 Check Point Quantum Security Management r77.30 이상 r81.20 미만, r81.20, r82, r82.10 버전이 영향을 받습니다.
- **랜섬웨어 연관**: Unknown

**개요**: CVE-2026-16232은 Check Point SmartConsole의 부적절한 인증(사용자가 누구인지 확인하는 과정) 취약점입니다. 이 취약점을 통해 인증되지 않은 원격 공격자가 SmartConsole 애플리케이션 로그인 토큰을 획득하여 최고 관리자 권한으로 인증할 수 있습니다.

**공격 영향**: 이 취약점을 악용하면 인증되지 않은 원격 공격자가 SmartConsole 시스템에 최고 관리자 권한(시스템의 모든 기능을 제어할 수 있는 권한)으로 접근할 수 있습니다. 이는 공격자가 보안 정책을 임의로 변경하거나, 네트워크 장치를 제어하거나, 중요한 시스템 설정을 조작하고, 민감한 정보에 접근하는 등 광범위한 시스템 제어 및 데이터 유출, 서비스 중단으로 이어질 수 있습니다.

**패치 우선순위**: CVSS v3.1 점수 9.1 (CRITICAL)로 볼 때, 이 취약점은 최고 등급의 우선순위를 가집니다. CISA는 공급업체 지침에 따라 완화 조치를 적용하고, CISA의 BOD 26-04 지침을 준수하며, 패치 기한(2026년 7월 25일) 내에 조치를 완료할 것을 강력히 권고하고 있습니다. 랜섬웨어 연관성은 제공된 데이터에 명시되지 않았습니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 현재 운영 중인 Check Point SmartConsole, Multi-Domain Security Management, Quantum Security Management 시스템을 식별하고, 해당 시스템의 버전을 확인합니다.
- 영향받는 버전을 사용 중인 경우, 즉시 공급업체(Check Point)가 제공하는 최신 패치 또는 완화 조치를 적용합니다.
- SmartConsole 관련 인증 로그 및 시스템 접근 기록을 주기적으로 모니터링하여 의심스러운 활동이나 비정상적인 로그인 시도가 있는지 확인합니다.
- CISA의 BOD 26-04(Prioritizing Security Updates Based on Risk) 지침을 참고하여 위험 평가 및 패치 우선순위 결정에 활용합니다.
- 만약 패치 적용이 불가능하다면, CISA 권고에 따라 해당 제품의 사용 중단을 고려하거나 대체 보안 제어를 마련합니다.
