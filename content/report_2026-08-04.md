## 1. CVE-2026-16812 — Arista VeloCloud Orchestrator On-Prem OS Command Injection Vulnerability

- **CVSS**: 10.0 <span class="severity-badge sev-critical">CRITICAL</span>
- **KEV 등재**: 예 (등재일 2026-07-27, 패치 기한 2026-07-30)
- **영향 제품**: Arista VeloCloud Orchestrator
- **영향 버전(NVD 기준)**: Arista VeloCloud Orchestrator 버전 정보 없음 5.2.0 이상 5.2.3.14 미만; Arista VeloCloud Orchestrator 버전 정보 없음 6.1.0 이상 6.1.3.4 미만; Arista VeloCloud Orchestrator 버전 정보 없음 6.4.0 이상 6.4.2.4 미만; Arista VeloCloud Orchestrator 7.0.0
- **랜섬웨어 연관**: Unknown

**개요**: Arista VeloCloud Orchestrator 온프레미스(On-Prem) 배포 환경에서 OS 명령 주입(OS Command Injection) 취약점(CVE-2026-16812)이 발견되었습니다. 이 취약점을 이용하면 원격 공격자가 특권이 있는 내부 기능에 접근하여 VeloCloud Orchestrator(VCO) 호스트에 영향을 미칠 수 있습니다.

**공격 영향**: 공격에 성공할 경우, 공격자는 VeloCloud Orchestrator 및 Orchestrator가 관리하는 데이터의 기밀성(데이터 유출), 무결성(데이터 변조), 가용성(서비스 중단)을 침해할 수 있습니다. 이는 시스템의 중요한 설정이나 운영 데이터를 임의로 조작하거나 파괴할 가능성을 의미합니다.

**패치 우선순위**: 이 취약점의 CVSS v3.1 점수는 10.0으로 '심각(CRITICAL)' 수준입니다. CISA KEV(Known Exploited Vulnerabilities) 카탈로그 등재 여부는 제공된 데이터에 명시되지 않았으며, 랜섬웨어 연관성도 알 수 없습니다. 그러나 매우 높은 CVSS 점수와 CISA의 긴급 패치 권고, 그리고 2026년 7월 30일까지의 패치 기한을 고려할 때, 즉시 최우선으로 패치를 적용하거나 완화 조치를 시행해야 합니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 영향받는 Arista VeloCloud Orchestrator 온프레미스 시스템의 버전 정보를 확인합니다.
- 제조사(Arista)에서 제공하는 패치 또는 완화 지침을 즉시 확인하고 적용합니다.
- 시스템에 대한 비정상적인 접근 시도나 활동을 모니터링합니다.
- 네트워크 경계에서 불필요한 포트를 차단하고, 접근 제어 목록(ACL)을 강화하여 외부로부터의 접근을 최소화합니다.
- Arista VeloCloud Orchestrator 시스템의 로그를 주기적으로 검토하여 의심스러운 명령 실행이나 오류가 있는지 확인합니다.

## 2. CVE-2026-50522 — Microsoft SharePoint Deserialization of Untrusted Data Vulnerability 

- **CVSS**: 9.8 <span class="severity-badge sev-critical">CRITICAL</span>
- **KEV 등재**: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
- **영향 제품**: Microsoft SharePoint
- **영향 버전(NVD 기준)**: Microsoft SharePoint Server 16.0.19725.20434 미만 버전 (이 중 특정 버전 정보가 명시되지 않은 경우 포함), Microsoft SharePoint Server 2016, Microsoft SharePoint Server 2019 제품이 이 취약점의 영향을 받습니다.
- **랜섬웨어 연관**: Unknown

**개요**: Microsoft SharePoint에서 신뢰할 수 없는 데이터 역직렬화(외부에서 받은 데이터를 프로그램이 다룰 수 있는 형태로 복원하는 과정) 취약점(CVE-2026-50522)이 발견되었습니다. 이 취약점을 이용하면 권한 없는 공격자가 네트워크를 통해 코드를 실행할 수 있습니다.

**공격 영향**: 공격자는 이 취약점을 악용하여 특별한 인증 없이도 네트워크를 통해 SharePoint 서버에 임의의 코드를 실행시킬 수 있습니다. 이는 서버 제어권 탈취, 중요 데이터 유출, 시스템 파괴 등 심각한 보안 사고로 이어질 수 있습니다.

**패치 우선순위**: CVSS 점수가 9.8로 매우 높고(CRITICAL), CISA의 BOD 26-04 지침에 따라 즉각적인 조치가 권고되므로, 최우선으로 패치해야 합니다. 랜섬웨어 연관 여부는 제공된 데이터에 명시되지 않았습니다. 패치 기한은 2026년 7월 25일입니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

- 영향받는 Microsoft SharePoint 서버를 식별합니다.
- Microsoft에서 제공하는 최신 보안 업데이트 및 완화 조치를 벤더 지침에 따라 즉시 적용합니다.
- CISA의 BOD 26-04(Prioritizing Security Updates Based on Risk) 지침을 준수하여 보안 업데이트를 우선 적용하고 패치 기한 내에 완료합니다.
- CISA의 'Forensics Triage Requirements' 지침을 검토하여 잠재적인 침해 사고에 대비한 포렌식 준비를 수행합니다.
- SharePoint 서버의 인터넷 노출 여부를 평가하고, 불필요하게 외부에 노출된 경우 접근 제어를 강화합니다.
- 클라우드 환경에서 SharePoint를 사용하는 경우, 해당 서비스 제공업체의 지침에 따라 완화 조치를 적용하거나, 완화 조치가 불가능할 경우 제품 사용 중단을 고려합니다.
- SharePoint 서버에서 비정상적인 네트워크 트래픽이나 의심스러운 프로세스 실행 여부를 지속적으로 모니터링합니다.

## 3. CVE-2026-16232 — Check Point SmartConsole Improper Authentication Vulnerability

- **CVSS**: 9.1 <span class="severity-badge sev-critical">CRITICAL</span>
- **KEV 등재**: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
- **영향 제품**: Check Point SmartConsole
- **영향 버전(NVD 기준)**: Check Point SmartConsole 제품군 중, Multi-Domain Security Management의 버전 r77.30 이상 r81.20 미만, r81.20, r82, r82.10이 영향을 받습니다. 또한 Quantum Security Management의 버전 r77.30 이상 r81.20 미만, r81.20, r82, r82.10도 영향을 받습니다. 특정 빌드 또는 패치 버전 정보는 제공된 데이터에 명시되지 않았습니다.
- **랜섬웨어 연관**: Unknown

**개요**: Check Point SmartConsole에서 부적절한 인증(Improper Authentication) 취약점(CVE-2026-16232)이 발견되었습니다. 이 취약점은 인증되지 않은 원격 공격자가 애플리케이션 로그인 토큰을 탈취하여 최고 관리자 권한으로 시스템에 접근할 수 있도록 허용합니다.

**공격 영향**: 이 취약점이 성공적으로 악용될 경우, 공격자는 아무런 인증 절차 없이 원격에서 SmartConsole 관리 시스템의 로그인 토큰을 얻어 최고 관리자 권한을 획득할 수 있습니다. 이는 공격자가 SmartConsole을 통해 관리되는 전체 보안 환경을 완전히 통제할 수 있음을 의미하며, 보안 정책 변경, 시스템 설정 조작, 민감 정보 접근 등 광범위한 피해를 유발할 수 있습니다.

**패치 우선순위**: 이 취약점은 CVSS 3.1 점수 9.1로 '심각(CRITICAL)' 등급에 해당하며, CISA가 2026년 7월 25일까지 패치 기한을 명시하여 매우 높은 우선순위를 가집니다. 랜섬웨어 연관성 및 KEV(Known Exploited Vulnerabilities) 카탈로그 등재 여부는 제공된 데이터에 명시되지 않았습니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 현재 운영 중인 Check Point SmartConsole 시스템의 버전을 확인하고, 영향받는 제품/버전에 해당하는지 식별합니다.
- Check Point에서 제공하는 공식 보안 권고 및 패치 적용 지침에 따라 즉시 업데이트를 수행하거나 완화 조치를 적용합니다.
- CISA의 BOD 26-04(위험 기반 보안 업데이트 우선순위 지정) 지침과 '포렌식 트리아지 요구사항'을 참고하여 보안 업데이트 및 대응 전략을 수립하고 준수합니다.
- SmartConsole이 클라우드 서비스로 운영될 경우, 해당 BOD 26-04 지침을 준수하거나, 완화 조치가 불가능할 경우 제품 사용을 중단하는 것을 고려합니다.
- SmartConsole 인스턴스의 인터넷 노출 여부를 평가하고, 모든 자산이 BOD 26-04 패치 지침을 따르도록 보장합니다.

**패치 우선순위**: 이 취약점은 CVSS v3.1 점수 9.8점으로 매우 심각(CRITICAL)하며, CISA KEV(Known Exploited Vulnerabilities) 카탈로그에 등재되어 있어 실제 공격에 악용될 가능성이 높으므로 가장 높은 우선순위로 패치를 적용해야 합니다. 패치 기한은 2026년 7월 24일입니다. 랜섬웨어 연관성은 현재 제공된 데이터에 명시되지 않음.

- BOD 26-04(Prioritizing Security Updates Based on Risk) 지침 및 CISA의 Forensics Triage Requirements를 준수하여 보안 업데이트를 적용합니다.
