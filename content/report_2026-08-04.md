## 2. CVE-2026-50522 — Microsoft SharePoint Deserialization of Untrusted Data Vulnerability 

- **CVSS**: 9.8 <span class="severity-badge sev-critical">CRITICAL</span>
- **KEV 등재**: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
- **영향 제품**: Microsoft SharePoint
- **영향 버전(NVD 기준)**: Microsoft SharePoint Server 2016, Microsoft SharePoint Server 2019, 그리고 빌드 번호 16.0.19725.20434 미만의 Microsoft SharePoint Server가 이 취약점의 영향을 받습니다.
- **랜섬웨어 연관**: Unknown

**개요**: CVE-2026-50522은 Microsoft SharePoint의 역직렬화(외부에서 받은 데이터를 프로그램이 다룰 수 있는 형태로 복원하는 과정) 취약점입니다. 이 취약점을 성공적으로 악용할 경우, 권한 없는 공격자가 네트워크를 통해 원격으로 코드를 실행할 수 있습니다.

**공격 영향**: 이 취약점은 CVSS 9.8점으로 매우 심각한 CRITICAL 등급입니다. 공격자는 이 취약점을 통해 원격 코드 실행(RCE)이 가능하여, 영향을 받는 SharePoint 서버에서 임의의 프로그램을 실행하거나 시스템을 완전히 제어할 수 있습니다. 이는 서버 내의 데이터 유출, 변조, 삭제는 물론, 악성코드 설치를 통한 추가적인 내부 시스템 침해로 이어질 수 있는 중대한 위협입니다.

**패치 우선순위**: 이 취약점은 CVSS 점수 9.8점(CRITICAL)으로 매우 심각하며, 원격 코드 실행(RCE) 가능성이 있어 최우선적으로 패치를 적용해야 합니다. CISA는 2026년 7월 25일까지 패치를 적용할 것을 권고하고 있습니다. 랜섬웨어 연관성은 현재 알려지지 않았으며, KEV(Known Exploited Vulnerabilities) 카탈로그 등재 여부는 제공된 데이터에 명시되지 않았습니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 운영 중인 Microsoft SharePoint 서버가 이 취약점의 영향을 받는 버전에 해당하는지 즉시 확인합니다.
- Microsoft에서 제공하는 최신 보안 업데이트 및 패치를 확인하고, 가능한 한 빨리 적용합니다.
- CISA의 BOD 26-04 지침에 따라 위험 기반 패치 우선순위를 결정하고 준수합니다.
- 인터넷에 노출된 SharePoint 서버가 있는 경우, 외부에서 직접 접근 가능한지 확인하고 추가적인 보안 강화 조치를 적용합니다.
- 클라우드 환경에서 SharePoint 서비스를 이용하는 경우, 해당 서비스 제공업체와 협력하여 패치 적용 여부 및 보안 상태를 확인하고 BOD 26-04 지침을 준수합니다.
- 완화 조치가 불가능하거나 즉시 적용하기 어려운 상황이라면, CISA 권고에 따라 제품 사용 중단을 검토합니다.
- CISA의 'Forensics Triage Requirements' 지침을 참조하여 잠재적 공격 발생 시 신속한 분석 및 대응을 위한 포렌식 준비 상태를 점검합니다.
