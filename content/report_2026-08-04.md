## 1. CVE-2026-16812 — Arista VeloCloud Orchestrator On-Prem OS Command Injection Vulnerability

- **CVSS**: 10.0 <span class="severity-badge sev-critical">CRITICAL</span>
- **KEV 등재**: 예 (등재일 2026-07-27, 패치 기한 2026-07-30)
- **영향 제품**: Arista VeloCloud Orchestrator
- **영향 버전(NVD 기준)**: Arista VeloCloud Orchestrator의 다음 버전이 영향을 받습니다: 5.2.0 이상 5.2.3.14 미만, 6.1.0 이상 6.1.3.4 미만, 6.4.0 이상 6.4.2.4 미만, 그리고 7.0.0 버전.
- **랜섬웨어 연관**: Unknown

**개요**: CVE-2026-16812은 Arista VeloCloud Orchestrator On-Prem 제품에서 발견된 OS 명령 주입(OS Command Injection) 취약점입니다. 이 취약점은 원격 공격자가 운영 체제 명령을 임의로 실행할 수 있도록 하여, 시스템의 중요한 기능에 접근하고 관리자(Orchestrator) 호스트에 영향을 미칠 수 있습니다. 성공적으로 악용될 경우, 시스템의 기밀성, 무결성, 가용성이 심각하게 침해될 수 있습니다.

**공격 영향**: 공격자는 이 취약점을 이용해 Arista VeloCloud Orchestrator 시스템에 원격으로 명령을 주입하고 실행할 수 있습니다. 이는 공격자가 오케스트레이터의 관리 권한을 획득하거나, 시스템에 저장된 중요 데이터를 탈취, 변조 또는 파괴할 수 있음을 의미합니다. 결과적으로, 시스템의 운영이 중단되거나 시스템에 의해 관리되는 데이터의 기밀성, 무결성, 가용성이 완전히 손상될 수 있습니다.

**패치 우선순위**: 이 취약점의 CVSS 점수는 10.0으로 '심각(CRITICAL)' 등급에 해당하며, CISA(미국 사이버 보안 및 인프라 보안국)에서 권고 조치를 발표하고 2026년 7월 30일까지의 패치 기한을 지정했습니다. 이는 즉각적인 패치 및 완화 조치가 필요한 최우선 보안 위협임을 시사합니다. 랜섬웨어 연관성은 현재 알 수 없습니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- Arista VeloCloud Orchestrator 시스템이 영향을 받는 버전에 해당되는지 확인합니다.
- 제공된 벤더(Arista)의 지침에 따라 최신 보안 패치를 적용하거나 완화 조치를 즉시 이행합니다.
- BOD 26-04(Prioritizing Security Updates Based on Risk) 지침 및 CISA의 권고 사항을 준수하여 보안 업데이트를 우선 적용합니다.
- 오케스트레이터 시스템의 인터넷 노출 여부를 평가하고, 불필요한 경우 외부 접근을 제한합니다.
- 클라우드 서비스를 사용하는 경우, 해당 BOD 26-04 지침을 따르거나, 완화 조치가 불가능할 경우 제품 사용을 중단하는 것을 고려합니다.

## 2. CVE-2026-50522 — Microsoft SharePoint Deserialization of Untrusted Data Vulnerability 

- **CVSS**: 9.8 <span class="severity-badge sev-critical">CRITICAL</span>
- **KEV 등재**: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
- **영향 제품**: Microsoft SharePoint
- **영향 버전(NVD 기준)**: Microsoft SharePoint Server 버전 정보 없음 16.0.19725.20434 미만; Microsoft SharePoint Server 2016; Microsoft SharePoint Server 2019
- **랜섬웨어 연관**: Unknown

**개요**: Microsoft SharePoint 제품에서 신뢰할 수 없는 데이터 역직렬화(외부에서 받은 데이터를 프로그램이 다룰 수 있는 형태로 복원하는 과정) 취약점(CVE-2026-50522)이 발견되었습니다. 이 취약점은 권한 없는 공격자가 네트워크를 통해 원격으로 코드를 실행할 수 있도록 허용합니다.

**공격 영향**: 권한이 없는 공격자가 이 취약점을 악용하면, 네트워크를 통해 Microsoft SharePoint 서버에 악성 코드를 원격으로 실행할 수 있습니다. 이는 서버의 모든 권한을 탈취하거나, 중요한 데이터에 접근하고 시스템을 변경하는 등 심각한 보안 침해로 이어질 수 있습니다.

**패치 우선순위**: CVSS 점수가 9.8점으로 매우 심각(CRITICAL)하며, 권한 없는 원격 코드 실행(RCE)이 가능하므로 즉시 패치를 적용해야 합니다. CISA는 2026년 7월 25일까지 패치를 완료할 것을 권고하고 있습니다. 랜섬웨어 연관 여부는 제공된 데이터에 명시되지 않았습니다.

Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

- 영향받는 버전(Microsoft SharePoint Server 버전 정보 없음 16.0.19725.20434 미만, Microsoft SharePoint Server 2016, Microsoft SharePoint Server 2019)에 해당하는 경우, 즉시 Microsoft에서 제공하는 보안 업데이트 및 패치를 적용합니다.
- CISA의 권고에 따라 공급업체 지침을 준수하여 완화 조치를 적용했는지 확인합니다.
- 패치 적용 후 시스템의 정상 작동 여부를 모니터링합니다.
- 사용 가능한 완화 조치가 없는 경우, CISA의 지침에 따라 제품 사용 중단을 고려하고, 각 자산의 인터넷 노출 여부를 평가하여 BOD 26-04 패치 지침을 준수하는지 확인합니다.

## 3. CVE-2026-16232 — Check Point SmartConsole Improper Authentication Vulnerability

- **CVSS**: 9.1 <span class="severity-badge sev-critical">CRITICAL</span>
- **KEV 등재**: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
- **영향 제품**: Check Point SmartConsole
- **영향 버전(NVD 기준)**: 영향을 받는 제품 및 버전은 다음과 같습니다: Check Point Multi-Domain Security Management의 r77.30 이상 r81.20 미만 버전(상세 버전 정보 없음), r81.20, r82, r82.10; Check Point Quantum Security Management의 r77.30 이상 r81.20 미만 버전(상세 버전 정보 없음), r81.20, r82, r82.10 입니다.
- **랜섬웨어 연관**: Unknown

**패치 우선순위**: CVSS 점수가 9.1(CRITICAL)로 매우 높으며, CISA에서 2026년 7월 25일까지 패치 기한을 명시하여 즉각적인 조치를 권고하고 있습니다. 랜섬웨어 연관성은 현재 알려지지 않았습니다. 따라서 이 취약점은 최우선으로 패치 또는 완화 조치를 적용해야 합니다.

- Check Point에서 제공하는 공식 패치 또는 완화 조치를 즉시 확인하고 적용합니다.

- SmartConsole의 인증 관련 로그를 주기적으로 검토하여 비정상적인 로그인 시도나 관리자 권한 획득 시도가 있는지 확인합니다.

## 4. CVE-2026-63030 — WordPress Core Interpretation Conflict Vulnerability

- **CVSS**: 9.8 <span class="severity-badge sev-critical">CRITICAL</span>
- **KEV 등재**: 예 (등재일 2026-07-21, 패치 기한 2026-07-24)
- **영향 제품**: WordPress Core
- **영향 버전(NVD 기준)**: WordPress Core 6.9.x 버전 중 6.9.5 미만의 모든 버전 (예: 6.9.0부터 6.9.4까지) 및 7.0.x 버전 중 7.0.2 미만의 모든 버전 (예: 7.0.0, 7.0.1)에 영향을 미칩니다.
- **랜섬웨어 연관**: Unknown

**개요**: WordPress Core에서 해석 충돌 취약점(CVE-2026-63030)이 발견되었습니다. 이 취약점은 공격자가 SQL Injection(데이터베이스에 악성 쿼리를 주입하여 데이터 조작 또는 탈취)을 수행하고 원격 코드 실행(시스템에서 임의의 명령을 실행)까지 가능하게 합니다. 특히, 이 취약점은 CVE-2026-60137과 연쇄적으로 공격될 수 있습니다.

**공격 영향**: 이 취약점이 성공적으로 악용될 경우, 공격자는 SQL Injection을 통해 WordPress 웹사이트의 데이터베이스에 저장된 민감한 정보(예: 사용자 계정 정보, 게시물 내용)를 조회, 수정 또는 삭제할 수 있습니다. 나아가 원격 코드 실행(공격자가 시스템에 명령을 보내 실행할 수 있는 능력)을 통해 웹 서버 전체를 제어하고, 악성 코드 설치, 데이터 파괴, 서비스 중단 등 심각한 피해를 발생시킬 수 있습니다.

**패치 우선순위**: 이 취약점은 CVSS 점수 9.8점(CRITICAL)으로 매우 높으며, SQL Injection 및 원격 코드 실행(RCE)이라는 치명적인 공격 가능성을 내포하고 있습니다. CISA의 BOD 26-04(위험 기반 보안 업데이트 우선순위 지정) 지침에 따라 2026년 7월 24일까지 패치를 적용해야 하므로 최우선으로 패치해야 합니다. 랜섬웨어 연관성은 현재 명시적으로 알려지지 않았으나, RCE 가능성으로 인해 랜섬웨어 공격의 초기 진입점으로 악용될 위험이 매우 높습니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 공급업체 지침에 따라 WordPress Core를 최신 패치 버전(6.9.5 이상 또는 7.0.2 이상)으로 즉시 업데이트하고, CISA의 BOD 26-04 '위험 기반 보안 업데이트 우선순위 지정' 지침을 준수하십시오.
- 각 시스템의 인터넷 노출 여부를 평가하고, CISA의 BOD 26-04 패치 지침을 철저히 따르십시오.
- CISA의 '포렌식 조사 요구사항'을 참고하여 시스템 침해가 의심되는 경우 초기 조사 및 대응 절차를 수행할 준비를 하십시오.
- 클라우드 서비스를 사용하는 경우 해당 BOD 26-04 지침을 따르거나, 완화 조치(패치 등)가 불가능할 경우 해당 WordPress 제품의 사용 중단을 고려하십시오.
