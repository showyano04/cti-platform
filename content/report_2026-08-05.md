## 1. CVE-2026-9198 — IBM Langflow Code Injection Vulnerability

- **CVSS**: 9.8 <span class="severity-badge sev-critical">CRITICAL</span>
- **KEV 등재**: 예 (등재일 2026-08-04, 패치 기한 2026-08-07)
- **영향 제품**: IBM Langflow
- **영향 버전(NVD 기준)**: langflow/langflow 버전 1.0.0 이상 1.10.1 미만
- **랜섬웨어 연관**: Unknown

**개요**: IBM Langflow 제품에서 인증되지 않은 공격자가 원격 코드 실행(RCE)을 수행할 수 있는 코드 인젝션 취약점(CVE-2026-9198)이 발견되었습니다. 이 취약점은 Langflow의 기본 배포 환경에서 악용될 수 있습니다.

**공격 영향**: 공격자는 이 취약점을 이용해 시스템에 임의의 코드를 실행할 수 있습니다. 이는 시스템의 데이터 유출, 변조, 삭제는 물론, 시스템을 완전히 제어하여 추가적인 악성 행위를 수행하거나 다른 내부 시스템으로 확산될 수 있는 심각한 결과를 초래합니다. 공격자는 별도의 인증 절차 없이 이 공격을 실행할 수 있습니다.

**패치 우선순위**: CVSS 점수가 9.8점으로 매우 높으며, CISA에서 즉시 완화 조치를 권고하고 2026년 8월 7일까지 패치 기한을 제시했으므로 최우선으로 패치를 적용해야 합니다. CISA의 BOD 26-04(위험 기반 보안 업데이트 우선순위 지정) 지침을 준수하여 신속하게 조치해야 합니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 영향받는 IBM Langflow 버전(1.0.0 이상 1.10.1 미만)을 사용 중인지 즉시 확인합니다.
- IBM Langflow 벤더가 제공하는 최신 보안 패치 또는 업데이트를 확인하고 지침에 따라 즉시 적용합니다.
- 현재 사용 중인 Langflow 배포 환경이 인터넷에 노출되어 있는지 확인하고, 노출되어 있다면 잠재적 위협에 대한 모니터링을 강화합니다.
- 벤더 패치 또는 완화 조치가 제공되지 않는 경우, CISA 권고에 따라 제품 사용 중단을 고려합니다.
- CISA의 'Forensics Triage Requirements' 지침에 따라 잠재적 침해에 대비한 포렌식 준비 태세를 점검하고 관련 로그를 확보합니다.

## 2. CVE-2026-34486 — Apache Tomcat Missing Encryption of Sensitive Data Vulnerability

- **CVSS**: 7.5 <span class="severity-badge sev-high">HIGH</span>
- **KEV 등재**: 예 (등재일 2026-08-04, 패치 기한 2026-08-07)
- **영향 제품**: Apache Tomcat
- **영향 버전(NVD 기준)**: apache/tomcat 9.0.116; apache/tomcat 10.1.53; apache/tomcat 11.0.20; redhat/jboss_web_server 7.0.0; redhat/enterprise_linux 8.0; redhat/enterprise_linux 9.0; redhat/enterprise_linux 10.0; redhat/enterprise_linux_els 7.0; redhat/enterprise_linux_eus 10.0; redhat/enterprise_linux_tus 8.8; redhat/enterprise_linux_update_services_for_sap_solutions 8.8; redhat/enterprise_linux_update_services_for_sap_solutions 9.2; redhat/enterprise_linux_update_services_for_sap_solutions 9.4; redhat/enterprise_linux_update_services_for_sap_solutions 9.6
- **랜섬웨어 연관**: Unknown

**개요**: CVE-2026-34486은 Apache Tomcat에서 민감한 데이터 암호화 누락으로 인해 EncryptInterceptor(데이터 암호화를 담당하는 구성 요소)를 우회할 수 있는 취약점입니다. 이 취약점이 악용되면, 암호화되어야 할 민감한 데이터가 보호되지 않은 상태로 노출될 수 있습니다.

**공격 영향**: 공격자가 이 취약점을 악용하면 Apache Tomcat의 EncryptInterceptor를 우회하여 암호화되지 않은 민감한 데이터를 탈취할 수 있습니다. 이는 시스템 내에 저장되거나 전송되는 사용자 정보, 설정 데이터 등 보호되어야 할 정보가 외부에 노출될 위험을 증가시킵니다. 데이터 유출로 인한 심각한 비즈니스 및 규제 준수 문제가 발생할 수 있습니다.

**패치 우선순위**: 높음 (HIGH) - CVSS 점수 7.5점으로 높고, CISA는 패치 적용 및 완화 조치를 권고하며 2026년 8월 7일까지의 기한을 제시했습니다. 랜섬웨어 연관성은 제공된 데이터에 명시되지 않았습니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

- 현재 운영 중인 Apache Tomcat 및 Red Hat 제품/버전이 CVE-2026-34486에 해당하는지 확인하십시오.
- 영향받는 시스템에 대해 벤더사(Apache, Red Hat)에서 제공하는 최신 패치 및 보안 업데이트를 적용하십시오.
- CISA의 BOD 26-04(위험 기반 보안 업데이트 우선순위 지정) 지침을 준수하여 패치 적용 및 완화 조치가 이루어졌는지 확인하십시오.
- 영향받는 자산의 인터넷 노출 여부를 평가하고, 외부 노출이 있는 경우 추가적인 보안 강화 조치를 검토하십시오.

- **CVSS**: 7.4 <span class="severity-badge sev-high">HIGH</span>
- **KEV 등재**: 예 (등재일 2026-08-04, 패치 기한 2026-08-07)
- **영향 제품**: N-able N-central

- N-able에서 제공하는 공식 패치 또는 업데이트를 적용하여 취약점을 해결합니다.

## 4. CVE-2026-18577 — N-able N-central Authentication Bypass Using an Alternate Path or Channel Vulnerability
