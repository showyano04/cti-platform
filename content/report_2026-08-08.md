# 일간 주요 취약점(CVE) 분석 리포트 — 2026-08-08

## 1. CVE-2026-8037 — Progress LoadMaster Command Injection Vulnerability

- **CVSS**: 9.6 <span class="severity-badge sev-critical">CRITICAL</span>
- **KEV 등재**: 예 (등재일 2026-08-07, 패치 기한 2026-08-10)
- **영향 제품**: Progress LoadMaster
- **영향 버전(NVD 기준)**: Progress LoadMaster 버전 7.2.54.18 미만, 또는 7.2.55.0 이상 7.2.63.2 미만 버전이 영향을 받습니다. 또한 Progress Connection Manager for ObjectScale 및 ECS Connection Manager 제품의 7.2.63.2 미만 버전도 영향을 받습니다. 제공된 데이터에 상세 버전 정보는 명시되지 않았습니다.
- **랜섬웨어 연관**: Unknown

**개요**: Progress LoadMaster 제품에서 명령 주입(Command Injection) 취약점(CVE-2026-8037)이 발견되었습니다. 이 취약점은 인증되지 않은 공격자가 여러 명령 엔드포인트에 제공되는 입력값에 대한 유효성 검사(sanitization)가 제대로 이루어지지 않는 점을 악용하여, LoadMaster 장비에 임의의 명령을 실행할 수 있게 합니다.

**공격 영향**: 이 취약점이 성공적으로 악용될 경우, 인증되지 않은 공격자는 LoadMaster 장비에서 운영 체제 수준의 임의 명령을 실행할 수 있습니다. 이는 공격자가 시스템을 완전히 제어하고, 설정 변경, 데이터 접근, 서비스 방해 등 심각한 보안 침해를 일으킬 수 있음을 의미합니다.

**패치 우선순위**: CVSS v3.1 점수 9.6점으로 '심각(CRITICAL)' 수준에 해당하며, 즉각적인 조치가 필요합니다. CISA KEV(Known Exploited Vulnerabilities) 목록 등재 여부 및 랜섬웨어 연관성은 제공된 데이터에 명시되지 않았습니다. 하지만 높은 CVSS 점수와 공격자가 인증 없이도 악용할 수 있다는 점을 고려할 때, 최우선적인 패치 적용이 권고됩니다. 패치 기한은 2026년 8월 10일입니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 운영 중인 Progress LoadMaster 및 관련 제품(Connection Manager for ObjectScale, ECS Connection Manager)의 버전을 확인합니다.
- 영향받는 버전을 사용 중인 경우, 벤더(Progress)의 지침에 따라 최신 보안 패치를 즉시 적용합니다.
- 인터넷에 노출된 LoadMaster 장비의 보안 설정을 재검토하고, 불필요한 네트워크 접근을 제한합니다.
- CISA의 BOD 26-04 지침(위험 기반 보안 업데이트 우선순위 지정)에 따라 보안 업데이트를 평가하고 적용 우선순위를 결정합니다.
- 패치 적용이 불가능한 경우, 벤더가 제공하는 완화 조치를 적용하고, 서비스 중단을 고려하여 추가적인 보안 대책을 마련합니다.
- 비정상적인 명령 실행 시도 또는 시스템 로그를 주기적으로 모니터링하여 잠재적인 악용 시도를 탐지합니다.

## 2. CVE-2026-63077 — JetBrains TeamCity Deserialization of Untrusted Data Vulnerability

- **CVSS**: 9.8 <span class="severity-badge sev-critical">CRITICAL</span>
- **KEV 등재**: 예 (등재일 2026-08-05, 패치 기한 2026-08-08)
- **영향 제품**: JetBrains TeamCity
- **영향 버전(NVD 기준)**: JetBrains TeamCity 2025.11.7 미만 버전, 그리고 JetBrains TeamCity 2026.1 이상 2026.1.3 미만 버전에 영향을 미칩니다. 특정 상세 버전 정보는 제공된 데이터에 명시되지 않았습니다.
- **랜섬웨어 연관**: Unknown

**개요**: CVE-2026-63077은 JetBrains TeamCity 제품에서 발생하는 역직렬화(외부에서 받은 데이터를 프로그램이 다룰 수 있는 형태로 복원하는 과정) 취약점입니다. 이 취약점은 에이전트 폴링 프로토콜을 통해 인증되지 않은 원격 코드 실행(시스템에 접근 권한 없이 명령을 실행하는 행위)을 허용할 수 있습니다.

**공격 영향**: 공격자는 에이전트 폴링 프로토콜을 이용하여 인증 없이(로그인 없이) 시스템에 접근할 수 있습니다. 이 취약점을 성공적으로 악용하면, 공격자는 영향을 받는 TeamCity 서버에서 임의의 코드를 실행할 수 있습니다. 이는 시스템의 완전한 제어권을 탈취하거나 중요한 데이터 유출, 시스템 파괴 등의 심각한 결과를 초래할 수 있습니다.

**패치 우선순위**: 이 취약점의 CVSS 점수는 9.8점으로 'CRITICAL' 수준이며, 원격 코드 실행이 가능한 점을 고려할 때 패치 우선순위가 매우 높습니다. 랜섬웨어 연관성은 'Unknown'으로 명시되어 있으며, KEV(Known Exploited Vulnerabilities) 등재 여부는 제공된 데이터에 명시되지 않았습니다. CISA 권고에 따라 2026년 8월 8일까지 패치를 적용해야 합니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 현재 운영 중인 JetBrains TeamCity 버전이 영향을 받는 범위에 해당하는지 즉시 확인하십시오.
- JetBrains에서 제공하는 최신 보안 패치 및 업데이트를 신속하게 적용하십시오.
- 공급업체의 지침에 따라 추가적인 완화 조치(예: 네트워크 분리, 접근 제어 강화 등)를 검토하고 적용하십시오.
- TeamCity 서버의 인터넷 노출 여부를 평가하고, 불필요한 경우 외부 접근을 제한하십시오.
- 패치 적용이 불가능하거나 완화 조치가 충분하지 않다고 판단될 경우, CISA 권고에 따라 해당 제품의 사용 중단을 고려하십시오.
- CISA의 BOD 26-04(Prioritizing Security Updates Based on Risk) 및 Forensics Triage Requirements 지침을 준수하여 보안 업데이트 및 관련 절차를 이행하십시오.

## 3. CVE-2026-9198 — IBM Langflow Code Injection Vulnerability

- **CVSS**: 9.8 <span class="severity-badge sev-critical">CRITICAL</span>
- **KEV 등재**: 예 (등재일 2026-08-04, 패치 기한 2026-08-07)
- **영향 제품**: IBM Langflow
- **영향 버전(NVD 기준)**: langflow/langflow 1.0.0 이상 1.10.1 미만 버전
- **랜섬웨어 연관**: Unknown

**개요**: IBM Langflow 제품에서 인증되지 않은 공격자가 시스템에 코드를 주입할 수 있는 취약점(CVE-2026-9198)이 발견되었습니다. 이 취약점을 성공적으로 악용할 경우, 공격자는 Langflow가 기본 배포된 환경에서 원격으로 시스템에 대한 완전한 제어 권한(원격 코드 실행)을 얻을 수 있습니다.

**공격 영향**: 이 취약점은 코드 주입 공격을 허용하여, 공격자가 시스템에 악성 코드를 실행할 수 있도록 합니다. 이는 시스템의 파일 삭제, 데이터 유출, 추가 악성 프로그램 설치 등 광범위한 피해를 초래할 수 있습니다. 특히, 인증 없이도 공격이 가능하므로, 해당 시스템이 인터넷에 노출되어 있다면 심각한 위협이 됩니다.

**패치 우선순위**: CVSS 점수가 9.8점으로 매우 심각하며, CISA가 권고 조치를 발표하고 특정 패치 기한을 지정한 점을 고려할 때, 즉시 최우선적으로 패치를 적용해야 합니다. CISA의 BOD 26-04(위험 기반 보안 업데이트 우선순위 지정) 지침을 준수하여 신속하게 대응해야 합니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 현재 운영 중인 Langflow의 버전이 1.0.0 이상 1.10.1 미만인지 확인합니다.
- 제공된 벤더(IBM)의 지침에 따라 최신 보안 패치를 즉시 적용합니다.
- 만약 패치가 불가능하거나 제공되지 않는 경우, CISA 권고에 따라 제품 사용 중단을 고려합니다.
- Langflow 인스턴스의 인터넷 노출 여부를 평가하고, 불필요한 경우 외부 접근을 제한합니다.
- 적용된 보안 업데이트가 CISA의 BOD 26-04 지침 및 포렌식 트리아지(사고 발생 시 신속한 분석 및 대응을 위한 초기 정보 수집) 요구 사항을 준수하는지 확인합니다.

## 4. CVE-2026-34486 — Apache Tomcat Missing Encryption of Sensitive Data Vulnerability

- **CVSS**: 7.5 <span class="severity-badge sev-high">HIGH</span>
- **KEV 등재**: 예 (등재일 2026-08-04, 패치 기한 2026-08-07)
- **영향 제품**: Apache Tomcat
- **영향 버전(NVD 기준)**: Apache Tomcat 9.0.116, 10.1.53, 11.0.20 버전; Red Hat JBoss Web Server 7.0.0 버전; Red Hat Enterprise Linux 8.0, 9.0, 10.0, ELS 7.0, EUS 10.0, TUS 8.8, Update Services for SAP Solutions 8.8, 9.2, 9.4, 9.6 버전이 영향을 받습니다.
- **랜섬웨어 연관**: Unknown

**개요**: CVE-2026-34486은 Apache Tomcat에서 민감 데이터 암호화 누락으로 인해 발생하는 취약점입니다. 이 취약점을 이용하면 EncryptInterceptor(암호화 처리기)를 우회할 수 있어 민감 데이터가 적절히 암호화되지 않고 노출될 위험이 있습니다. 이 취약점은 CVSS v3.1 점수 7.5점으로 '높음' 심각도에 해당하며, CVE-2025-24813과 연쇄 공격이 가능하여 잠재적인 위협이 더욱 커질 수 있습니다.

**공격 영향**: 공격자는 이 취약점을 이용하여 Apache Tomcat의 EncryptInterceptor를 우회하고, 의도하지 않게 민감 데이터가 암호화되지 않은 채로 노출되도록 만들 수 있습니다. 특히 CVE-2025-24813과 연쇄 공격이 가능하므로, 공격자는 이 두 취약점을 결합하여 시스템에 대한 제어를 강화하거나 더 광범위한 데이터 유출을 시도하는 등 잠재적으로 더 큰 피해를 입힐 수 있습니다.

**패치 우선순위**: CVSS v3.1 점수 7.5점으로 '높음' 심각도에 해당합니다. CISA는 해당 취약점에 대한 권고 조치를 발표하였고, 패치 기한이 2026년 8월 7일로 명시되어 있습니다. 랜섬웨어 연관 여부는 제공된 데이터에 명시되지 않았으나, CISA 권고 및 패치 기한을 고려할 때 즉각적인 조치가 필요한 높은 우선순위의 취약점으로 판단됩니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

**운영자 확인 사항**:
- 영향받는 Apache Tomcat, Red Hat JBoss Web Server, Red Hat Enterprise Linux 시스템의 버전을 식별하고, 최신 보안 패치가 적용되었는지 확인하십시오.
- 공급업체(Apache, Red Hat)에서 제공하는 보안 업데이트 및 패치 적용 지침에 따라 즉시 시스템을 업데이트하십시오.
- EncryptInterceptor의 설정 및 동작 상태를 검토하여 민감 데이터가 의도대로 암호화되고 있는지 확인하십시오.
- 시스템 내 민감 데이터 처리 로직에서 암호화가 누락된 부분이 없는지 점검하고, 필요한 경우 추가 보안 제어를 구현하십시오.
- CISA의 BOD 26-04 지침에 따라 이 취약점의 인터넷 노출 여부를 평가하고, 권고된 패치 기한(2026년 8월 7일) 내에 조치를 완료하십시오.
- 이 취약점은 CVE-2025-24813과 연쇄 공격이 가능하므로, 관련 시스템에서 해당 취약점에 대한 정보 확인 및 조치 여부도 함께 확인하십시오.

## 5. CVE-2026-18556 — N-able N-central Authentication Bypass Using an Alternate Path or Channel Vulnerability

- **CVSS**: 7.4 <span class="severity-badge sev-high">HIGH</span>
- **KEV 등재**: 예 (등재일 2026-08-04, 패치 기한 2026-08-07)
- **영향 제품**: N-able N-central
- **영향 버전(NVD 기준)**: N-able N-central 제품의 2026.1 이하 버전이 영향을 받습니다. 제공된 데이터에 상세 버전 정보는 명시되지 않았습니다.
- **랜섬웨어 연관**: Unknown

**개요**: N-able N-central 제품에서 인증 우회(Authentication Bypass) 취약점(CVE-2026-18556)이 발견되었습니다. 이 취약점을 성공적으로 악용하면 공격자가 정상적인 인증 절차를 거치지 않고 시스템에 접근할 수 있게 됩니다.

**공격 영향**: 이 취약점이 악용될 경우, 공격자는 N-able N-central 시스템에 대해 비인가 접근(Unauthorized Access)을 획득할 수 있습니다. 이는 공격자가 시스템 관리 기능에 접근하거나, 저장된 데이터를 열람 또는 유출하고, 시스템 설정을 임의로 변경하거나, 악성 코드를 실행하는 등 다양한 악의적인 활동을 수행할 수 있게 만듭니다.

**패치 우선순위**: CISA가 지정한 패치 기한(2026년 8월 7일)을 고려할 때, 이 취약점은 높은 우선순위로 패치해야 합니다. CVSS 점수가 7.4(높음)로 평가되어 시스템 보안에 심각한 위험을 초래할 수 있으며, CISA는 벤더 지침에 따라 완화 조치를 적용하고 CISA의 BOD 26-04 지침을 준수할 것을 권고하고 있습니다. 랜섬웨어 연관 여부는 제공된 데이터에 명시되지 않았습니다.

**공식 패치·완화조치(CISA 권고)**: Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes).
