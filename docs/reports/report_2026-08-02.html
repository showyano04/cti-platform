1. CVE-2026-16812 — Arista VeloCloud Orchestrator On-Prem OS Command Injection Vulnerability

  • CVSS: 10.0 (CRITICAL)
  • KEV 등재: 예 (등재일 2026-07-27, 패치 기한 2026-07-30)
  • 영향 제품: Arista VeloCloud Orchestrator
  • 영향 버전(NVD 기준): Arista VeloCloud Orchestrator의 버전 정보 없음 5.2.0 이상 5.2.3.14 미만, 버전 정보 없음 6.1.0 이상 6.1.3.4 미만, 버전 정보 없음 6.4.0 이상 6.4.2.4 미만, 그리고 7.0.0 버전이 영향을 받습니다.
  • 랜섬웨어 연관: Unknown

개요: CVE-2026-16812은 Arista VeloCloud Orchestrator On-Prem 제품에서 발견된 OS 명령 주입 취약점입니다. 이 취약점은 원격 공격자가 운영체제 명령을 임의로 실행할 수 있도록 허용하여, 권한이 있는 내부 기능에 접근하고 VeloCloud Orchestrator 호스트에 영향을 줄 수 있습니다.

공격 영향: 공격에 성공하면 공격자는 원격으로 VeloCloud Orchestrator 호스트에서 임의의 운영체제 명령(OS Command)을 실행할 수 있습니다. 이는 오케스트레이터와 오케스트레이터가 관리하는 데이터의 기밀성(데이터 유출), 무결성(데이터 변조), 가용성(서비스 중단)을 모두 침해할 수 있는 심각한 결과를 초래합니다. 공격자는 이를 통해 내부 시스템에 접근하여 추가적인 공격을 시도할 가능성이 있습니다.

패치 우선순위: 이 취약점의 CVSS 점수는 10.0으로 '심각(CRITICAL)' 등급이며, CISA KEV(Known Exploited Vulnerabilities) 목록에는 등재되지 않았지만 CISA에서 적극적으로 권고 조치를 내리고 있습니다. 랜섬웨어 연관성은 제공된 데이터에 명시되지 않았습니다. 2026년 7월 30일이라는 패치 기한이 있으나, CVSS 점수가 매우 높아 잠재적 위험이 크므로 최우선으로 패치를 적용해야 합니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 영향받는 VeloCloud Orchestrator 시스템을 식별하고, 해당 시스템의 현재 버전을 확인합니다. - Arista에서 제공하는 벤더 지침에 따라 최신 패치 또는 완화 조치를 즉시 적용합니다. - CISA의 BOD 26-04(위험 기반 보안 업데이트 우선순위 지정) 지침을 준수하여 패치 진행 상황을 관리합니다. - 각 자산의 인터넷 노출 여부를 평가하고, BOD 26-04의 패치 지침을 철저히 따르고 있는지 확인합니다. - 클라우드 서비스를 사용하는 경우 해당 BOD 26-04 지침을 따르거나, 만약 완화 조치가 제공되지 않는다면 제품 사용 중단을 검토합니다.

2. CVE-2026-50522 — Microsoft SharePoint Deserialization of Untrusted Data Vulnerability

  • CVSS: 9.8 (CRITICAL)
  • KEV 등재: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
  • 영향 제품: Microsoft SharePoint

  • 랜섬웨어 연관: Unknown

개요: Microsoft SharePoint 제품에서 신뢰할 수 없는 데이터의 역직렬화(외부에서 받은 데이터를 프로그램이 다룰 수 있는 형태로 복원하는 과정) 취약점(CVE-2026-50522)이 발견되었습니다. 이 취약점은 인증되지 않은 공격자가 네트워크를 통해 원격으로 코드를 실행할 수 있게 합니다.

공격 영향: 공격자는 취약한 SharePoint 서버에 특수하게 조작된 데이터를 전송하여 서버가 이를 역직렬화하는 과정에서 악성 코드를 실행할 수 있습니다. 이는 공격자가 원격으로 서버를 완전히 제어하고, 중요한 데이터를 접근, 변조, 삭제하거나 추가적인 악성 프로그램을 설치하는 등의 심각한 피해를 유발할 수 있습니다. 조직의 핵심 시스템 마비, 데이터 유출 등 광범위한 피해로 이어질 수 있습니다.

패치 우선순위: CVSS 점수 9.8점으로 '긴급(CRITICAL)' 수준의 매우 높은 심각도를 가지며, CISA는 해당 취약점에 대해 2026년 7월 25일까지 패치를 적용할 것을 권고했습니다. KEV(Known Exploited Vulnerabilities) 등재 여부 및 랜섬웨어 연관 여부는 제공된 데이터에 명시되지 않았으나, 즉각적인 보안 업데이트가 필요합니다. CISA의 BOD 26-04(위험 기반 보안 업데이트 우선순위 지정) 지침을 준수하여 조치를 취해야 합니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 현재 운영 중인 Microsoft SharePoint 서버의 버전을 확인하고, 영향받는 버전에 해당하는지 점검합니다. - Microsoft에서 제공하는 최신 보안 업데이트를 즉시 적용하여 취약점을 해결합니다. - 업데이트 적용이 불가능할 경우, Microsoft SharePoint 서비스의 인터넷 노출 여부를 평가하고 CISA 권고에 따라 해당 제품의 사용 중단을 고려합니다. - CISA의 BOD 26-04 지침에 따라 자산의 위험도를 평가하고 보안 업데이트 우선순위를 지정합니다. - CISA의 포렌식 트리아지(Forensics Triage) 요구사항을 숙지하고 유사시 대응 계획을 수립합니다.

4. CVE-2026-63030 — WordPress Core Interpretation Conflict Vulnerability

  • CVSS: 9.8 (CRITICAL)
  • KEV 등재: 예 (등재일 2026-07-21, 패치 기한 2026-07-24)
  • 영향 제품: WordPress Core
  • 영향 버전(NVD 기준): WordPress Core 6.9 이상 6.9.5 미만 버전, 7.0 이상 7.0.2 미만 버전.
  • 랜섬웨어 연관: Unknown

개요: WordPress Core에서 해석 충돌 취약점(Interpretation Conflict Vulnerability)이 발견되었습니다. 이 취약점은 공격자가 SQL Injection(데이터베이스에 악의적인 쿼리를 삽입하는 공격)을 수행하고 원격 코드 실행(RCE, 공격자가 원격에서 서버에 임의의 코드를 실행하여 시스템을 완전히 제어할 수 있는 공격)까지 가능하게 할 수 있습니다. 이 취약점은 CVE-2026-60137과 연쇄적으로 공격될 수 있습니다.

공격 영향: 이 취약점을 악용하면 공격자는 웹 애플리케이션의 데이터베이스에 직접 접근하여 민감한 정보를 조회, 수정 또는 삭제할 수 있는 SQL Injection을 수행할 수 있습니다. 나아가 원격 코드 실행(RCE)을 통해 웹사이트 변조, 사용자 데이터 유출, 백도어 설치를 통한 장기적인 시스템 장악 등 심각한 결과를 초래할 수 있습니다.

패치 우선순위: CVSS 점수 9.8점으로 매우 심각(CRITICAL)하며, CISA BOD 26-04 지침에 따라 2026년 7월 24일까지 패치를 적용해야 하는 고위험 취약점입니다. 따라서 최우선으로 패치해야 합니다. 랜섬웨어 연관성은 제공된 데이터에 명시되지 않았습니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 현재 운영 중인 WordPress Core 버전이 영향을 받는 범위(6.9 이상 6.9.5 미만, 7.0 이상 7.0.2 미만)에 해당하는지 즉시 확인합니다. - 영향을 받는 버전이라면, 벤더(WordPress)가 제공하는 최신 보안 업데이트를 가능한 한 빨리 적용합니다. - 패치 적용 전, 중요 데이터 백업 및 테스트 환경에서 업데이트 호환성을 검증합니다. - CISA BOD 26-04 지침에 따라 자산의 인터넷 노출 여부를 평가하고, 해당 패치 기한(2026년 7월 24일)까지 패치를 완료합니다. - 공격 발생 시 대응을 위해 CISA의 'Forensics Triage Requirements'를 참고하여 포렌식 준비 태세를 갖춥니다. - 보안 솔루션(예: 웹 방화벽, 침입 방지 시스템)에서 SQL Injection 공격 시도를 탐지하고 차단하는 규칙이 올바르게 적용되어 있는지 검토하고 강화합니다. - 가능하다면, 이 취약점과 연쇄 공격이 가능한 CVE-2026-60137에 대한 패치 및 방어 대책도 함께 검토하고 적용합니다.
