주간 주요 취약점(CVE) 분석 리포트 — 2026-08-02

2. CVE-2026-50522 — Microsoft SharePoint Deserialization of Untrusted Data Vulnerability

  • CVSS: 9.8 (CRITICAL)
  • KEV 등재: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
  • 영향 제품: Microsoft SharePoint
  • 영향 버전(NVD 기준): Microsoft SharePoint Server 버전 16.0.19725.20434 미만, Microsoft SharePoint Server 2016, Microsoft SharePoint Server 2019가 영향을 받습니다.
  • 랜섬웨어 연관: Unknown

개요: Microsoft SharePoint 제품에 신뢰할 수 없는 데이터 역직렬화(외부에서 받은 데이터를 프로그램이 다룰 수 있는 형태로 복원하는 과정) 취약점(CVE-2026-50522)이 발견되었습니다. 이 취약점을 이용하면 권한이 없는 공격자가 네트워크를 통해 임의의 코드를 실행할 수 있습니다.

공격 영향: 이 취약점이 성공적으로 악용될 경우, 공격자는 원격에서 악성 코드를 실행하여 해당 SharePoint 서버에 대한 완전한 제어 권한을 획득할 수 있습니다. 이는 시스템의 기밀성, 무결성, 가용성에 심각한 영향을 미칠 수 있습니다.

패치 우선순위: CVSS 점수 9.8 (CRITICAL)로 매우 높은 심각도를 가지며, CISA KEV(Known Exploited Vulnerabilities) 목록 등재 여부와 랜섬웨어 연관 여부는 제공된 데이터에 명시되지 않았습니다. CISA는 2026년 7월 25일까지 패치 적용을 권고하고 있어 즉각적인 조치가 필요합니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 사용 중인 Microsoft SharePoint 제품이 CVE-2026-50522의 영향 범위에 포함되는지 확인하십시오. - Microsoft가 제공하는 보안 업데이트 및 완화 조치 지침을 즉시 확인하고 적용하십시오. - CISA의 BOD 26-04 지침에 따라 이 취약점의 보안 업데이트 우선순위를 높게 설정하고 기한 내에 적용하십시오. - 공격 시도 여부를 탐지하고 분석하기 위해 CISA의 'Forensics Triage Requirements'를 검토하고 필요한 포렌식 준비 조치를 이행하십시오. - SharePoint 자산의 인터넷 노출 여부를 평가하고, 필요한 경우 접근 제어 강화 등 추가적인 보안 조치를 고려하십시오. - 클라우드 기반 SharePoint 서비스를 이용하는 경우, BOD 26-04 지침에 따라 서비스 공급자와 협력하여 보안 업데이트가 적용되었는지 확인하십시오. - 만약 적절한 완화 조치가 없거나 패치 적용이 불가능한 경우, 해당 제품의 사용 중단을 신중하게 검토하십시오.
