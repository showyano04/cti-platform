1. CVE-2026-16812 — Arista VeloCloud Orchestrator On-Prem OS Command Injection Vulnerability

  • CVSS: 10.0 CRITICAL
  • KEV 등재: 예 (등재일 2026-07-27, 패치 기한 2026-07-30)
  • 영향 제품: Arista VeloCloud Orchestrator
  • 영향 버전(NVD 기준): Arista VeloCloud Orchestrator On-Prem 제품의 다음 버전들이 영향을 받습니다: 버전 정보 없음 5.2.0 이상 5.2.3.14 미만; 버전 정보 없음 6.1.0 이상 6.1.3.4 미만; 버전 정보 없음 6.4.0 이상 6.4.2.4 미만; 7.0.0 버전.
  • 랜섬웨어 연관: Unknown

개요: Arista VeloCloud Orchestrator On-Prem 제품에서 운영 체제 명령 주입(OS Command Injection) 취약점이 발견되었습니다. 이 취약점을 이용하면 원격 공격자가 권한 있는 내부 기능에 접근하여 VeloCloud Orchestrator 호스트에 영향을 줄 수 있습니다. 성공적인 공격 시 오케스트레이터 및 오케스트레이터가 관리하는 데이터의 기밀성, 무결성, 가용성이 손상될 수 있습니다.

공격 영향: 이 취약점은 원격 공격자가 Arista VeloCloud Orchestrator On-Prem 시스템에 운영 체제 명령을 주입(외부에서 받은 데이터를 프로그램이 다룰 수 있는 형태로 복원하는 과정에서 임의의 명령을 실행)할 수 있게 합니다. 공격에 성공하면 공격자는 VeloCloud Orchestrator의 내부 기능에 접근하여 시스템을 제어하거나 민감한 정보를 탈취할 수 있습니다. 이는 오케스트레이터가 관리하는 네트워크 설정, 사용자 정보 등 중요한 데이터의 기밀성(정보 유출), 무결성(데이터 변조), 가용성(서비스 중단)에 심각한 영향을 미칠 수 있습니다.

패치 우선순위: CVSS v3.1 점수 10.0으로 '심각(CRITICAL)' 등급입니다. CISA KEV 등재 여부와 랜섬웨어 연관성은 제공된 데이터에 명시되지 않았습니다. CISA가 즉시 조치를 권고했으며, 2026년 7월 30일의 패치 기한을 고려할 때, 이 취약점은 최우선적으로 패치 및 완화 조치를 적용해야 합니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 영향받는 Arista VeloCloud Orchestrator On-Prem 시스템 목록을 파악하고 최신 패치 및 보안 업데이트 적용 현황을 확인합니다. - Arista 벤더가 제공하는 지침에 따라 완화 조치를 즉시 적용합니다. - CISA의 BOD 26-04(위험 기반 보안 업데이트 우선순위 지정) 지침을 준수하여 보안 업데이트 우선순위를 정하고 적용합니다. - 제품의 인터넷 노출 여부를 평가하고, 인터넷에 노출된 경우 BOD 26-04 패치 지침을 철저히 따릅니다. - 완화 조치가 불가능한 경우, 클라우드 서비스에 대한 BOD 26-04 지침을 따르거나 제품 사용을 중단하는 것을 고려합니다. - 향후 발생할 수 있는 보안 사고에 대비하여 CISA의 '포렌식 트리아지 요구사항'을 검토하고 준비합니다.

참고 자료: - https://www.arista.com/en/support/advisories-notices/security-advisory/24364-security-advisory-0144 - https://www.cisa.gov/news-events/directives/bod-26-04-prioritizing-security-updates-based-risk - https://www.cisa.gov/news-events/directives/bod-26-04-implementation-guidance-prioritizing-security-updates-based-risk - https://nvd.nist.gov/vuln/detail/CVE-2026-16812

2. CVE-2026-50522 — Microsoft SharePoint Deserialization of Untrusted Data Vulnerability

  • CVSS: 9.8 CRITICAL
  • KEV 등재: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
  • 영향 제품: Microsoft SharePoint
  • 영향 버전(NVD 기준): Microsoft SharePoint Server의 특정 버전이 영향을 받습니다. 구체적으로는 Microsoft SharePoint Server (버전 정보 없음) 16.0.19725.20434 미만, Microsoft SharePoint Server 2016, 그리고 Microsoft SharePoint Server 2019가 해당됩니다.
  • 랜섬웨어 연관: Unknown

개요: Microsoft SharePoint 제품에서 신뢰할 수 없는 데이터의 역직렬화(외부에서 받은 데이터를 프로그램이 다룰 수 있는 형태로 복원하는 과정) 취약점(CVE-2026-50522)이 발견되었습니다. 이 취약점을 이용하면 권한 없는 공격자가 네트워크를 통해 임의의 코드를 실행할 수 있습니다.

공격 영향: 이 취약점이 악용될 경우, 권한 없는 공격자가 특별히 조작된 데이터를 SharePoint 서버로 전송하여, 서버에서 임의의 코드(예: 악성 프로그램 설치, 데이터 탈취, 시스템 설정 변경 등)를 실행할 수 있습니다. 이는 시스템의 완전한 장악으로 이어질 수 있으며, 심각한 데이터 유출이나 서비스 중단으로 이어질 가능성이 있습니다.

패치 우선순위: 이 취약점은 CVSS 점수 9.8점으로 '심각(CRITICAL)' 등급에 해당합니다. CISA(미국 사이버보안 및 인프라 보안국)에서 권고 조치를 발표하고 2026년 7월 25일까지 패치 기한을 명시했으므로, 즉각적인 보안 업데이트 적용이 매우 중요합니다. 랜섬웨어 연관성은 현재 제공된 데이터에 명시되지 않았습니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 운영 중인 Microsoft SharePoint Server의 정확한 버전을 확인합니다. - 영향받는 버전을 사용 중인 경우, Microsoft에서 제공하는 최신 보안 업데이트 및 패치 적용 지침을 즉시 확인하고 따릅니다. - CISA의 BOD 26-04 지침에 따라 보안 업데이트 우선순위를 정하고 적용합니다. - SharePoint 자산의 인터넷 노출 여부를 평가하고, 불필요한 노출을 최소화하기 위한 보안 조치를 강화합니다. - 벤더의 완화 조치(mitigation)가 없는 경우, 제품 사용 중단을 고려하거나 대체 솔루션으로의 전환 계획을 수립합니다. - CISA의 '포렌식 트리아지 요구사항(Forensics Triage Requirements)'에 따라 잠재적 침해에 대비한 절차를 수립하고 점검합니다.

참고 자료: - https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-50522 - https://www.cisa.gov/news-events/directives/bod-26-04-prioritizing-security-updates-based-risk - https://www.cisa.gov/news-events/directives/bod-26-04-implementation-guidance-prioritizing-security-updates-based-risk - https://nvd.nist.gov/vuln/detail/CVE-2026-50522
