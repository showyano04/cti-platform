1. CVE-2026-16812 — Arista VeloCloud Orchestrator On-Prem OS Command Injection Vulnerability

  • CVSS: 10.0 CRITICAL
  • KEV 등재: 예 (등재일 2026-07-27, 패치 기한 2026-07-30)
  • 영향 제품: Arista VeloCloud Orchestrator
  • 영향 버전(NVD 기준): Arista VeloCloud Orchestrator On-Prem의 특정 버전이 영향을 받습니다: 버전 정보 없음 5.2.0 이상 5.2.3.14 미만, 버전 정보 없음 6.1.0 이상 6.1.3.4 미만, 버전 정보 없음 6.4.0 이상 6.4.2.4 미만, 그리고 7.0.0 버전입니다.
  • 랜섬웨어 연관: Unknown

개요: Arista VeloCloud Orchestrator On-Prem 제품에서 OS 명령 주입(운영체제에서 실행될 명령어를 공격자가 삽입하여 임의의 코드를 실행시키는 공격 기법) 취약점(CVE-2026-16812)이 발견되었습니다. 이 취약점을 이용하면 원격 공격자가 특권이 있는 내부 기능에 접근하여 VeloCloud Orchestrator(VCO) 호스트에 영향을 줄 수 있습니다.

공격 영향: 원격 공격자가 이 취약점을 성공적으로 악용할 경우, VeloCloud Orchestrator(VCO)의 기밀성(인가되지 않은 사용자에게 정보가 노출되는 것), 무결성(정보가 무단으로 변경되거나 손상되는 것), 가용성(정상적인 서비스 또는 정보 접근이 방해받는 것)을 침해할 수 있습니다. 이는 오케스트레이터 및 오케스트레이터가 관리하는 데이터에 심각한 영향을 미칠 수 있습니다.

패치 우선순위: CVSS v3.1 점수가 10.0으로 '심각(CRITICAL)'하며, CISA KEV에는 등재되지 않았습니다. 랜섬웨어 연관성은 제공된 데이터에 명시되지 않았습니다. CISA가 2026년 7월 30일까지 패치 또는 완화 조치를 권고하고 있으므로, 최우선으로 패치를 적용해야 합니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 영향을 받는 Arista VeloCloud Orchestrator On-Prem 제품 및 버전을 식별합니다. - 벤더 지침에 따라 최신 패치를 적용하거나 완화 조치를 수행합니다. - CISA의 BOD 26-04(Prioritizing Security Updates Based on Risk) 지침을 준수하는지 확인합니다. - 클라우드 서비스를 사용하는 경우, 해당 BOD 26-04 지침을 따르거나, 완화 조치가 불가능할 경우 제품 사용 중단을 고려합니다. - 각 자산의 인터넷 노출 여부를 평가하고 BOD 26-04 패치 지침을 준수하는지 확인합니다.

2. CVE-2026-50522 — Microsoft SharePoint Deserialization of Untrusted Data Vulnerability

  • CVSS: 9.8 CRITICAL
  • KEV 등재: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
  • 영향 제품: Microsoft SharePoint
  • 영향 버전(NVD 기준): Microsoft SharePoint Server 2016, Microsoft SharePoint Server 2019, 그리고 Microsoft SharePoint Server의 16.0.19725.20434 미만 버전이 취약한 것으로 확인되었습니다.
  • 랜섬웨어 연관: Unknown

개요: Microsoft SharePoint의 역직렬화(외부에서 받은 데이터를 프로그램이 다룰 수 있는 형태로 복원하는 과정) 취약점(CVE-2026-50522)이 발견되었습니다. 이 취약점은 권한 없는 공격자가 네트워크를 통해 코드를 실행할 수 있도록 허용합니다.

공격 영향: 이 취약점은 Microsoft SharePoint 서버에서 신뢰할 수 없는 데이터를 역직렬화하는 과정에서 발생합니다. 성공적인 공격이 이루어질 경우, 공격자는 네트워크를 통해 악성 코드를 SharePoint 서버에 원격으로 실행(RCE)할 수 있습니다. 이는 서버의 모든 권한을 획득하거나, 데이터를 유출 및 변조하거나, 서비스를 중단시키는 등 심각한 피해로 이어질 수 있습니다.

패치 우선순위: 이 취약점은 CVSS 점수 9.8(CRITICAL)로 매우 높은 심각도를 가집니다. CISA는 해당 취약점에 대한 패치 적용을 권고하며, 2026년 7월 25일까지 조치 기한을 명시했습니다. KEV 등재 여부와 랜섬웨어 연관성은 제공된 데이터에 명시되지 않았지만, 심각한 CVSS 점수와 CISA의 긴급 조치 권고에 따라 최우선적으로 패치를 적용해야 합니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 영향받는 Microsoft SharePoint 시스템을 식별하고, 현재 설치된 버전이 취약한 버전에 해당하는지 확인합니다. - Microsoft에서 제공하는 최신 보안 업데이트 및 패치를 즉시 적용하여 취약점을 해결합니다. - SharePoint 서버의 인터넷 노출 여부를 평가하고, 불필요한 경우 외부 접근을 제한하거나 방화벽 규칙을 강화합니다. - 클라우드 환경에서 SharePoint 서비스를 사용 중인 경우, 해당 서비스에 대한 공급업체 지침을 확인하고 권고되는 완화 조치를 적용합니다. - 패치 적용 후 시스템 안정성 및 서비스 연속성을 확인합니다.

3. CVE-2026-16232 — Check Point SmartConsole Improper Authentication Vulnerability

  • CVSS: 9.1 CRITICAL
  • KEV 등재: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
  • 영향 제품: Check Point SmartConsole
  • 영향 버전(NVD 기준): checkpoint/multi-domain_security_management r77.30 이상 r81.20 미만 버전; checkpoint/multi-domain_security_management r81.20 버전; checkpoint/multi-domain_security_management r82 버전; checkpoint/multi-domain_security_management r82.10 버전; checkpoint/quantum_security_management r77.30 이상 r81.20 미만 버전; checkpoint/quantum_security_management r81.20 버전; checkpoint/quantum_security_management r82 버전; checkpoint/quantum_security_management r82.10 버전에 영향을 미칩니다. (영향받는 제품/버전의 상세 정보는 NVD CPE 데이터에 따름)
  • 랜섬웨어 연관: Unknown

개요: CVE-2026-16232은 Check Point SmartConsole의 부적절한 인증(Improper Authentication) 취약점으로, 인증되지 않은 원격 공격자가 애플리케이션 로그인 토큰을 획득하여 관리자 권한으로 인증할 수 있도록 허용합니다.

공격 영향: 이 취약점은 인증되지 않은 원격 공격자가 Check Point SmartConsole의 로그인 토큰을 탈취하여 최고 관리자 권한으로 시스템에 접근할 수 있게 합니다. 일단 관리자 권한을 획득하면, 공격자는 시스템 설정을 변경하거나, 보안 정책을 조작하거나, 민감한 정보에 접근하는 등 시스템에 대한 완전한 통제권을 행사하여 심각한 피해를 유발할 수 있습니다.

패치 우선순위: 이 취약점은 CVSS v3.1 점수 9.1점으로 '긴급(CRITICAL)' 수준에 해당하며, CISA가 2026년 7월 25일까지 패치 기한을 명시하고 권고 조치를 발표했으므로 최우선적으로 패치해야 합니다. KEV 등재 여부 및 랜섬웨어 연관성은 제공된 데이터에 명시되지 않았습니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 현재 운영 중인 Check Point SmartConsole의 제품 및 버전 정보를 확인하고, 영향받는 버전에 해당하는지 파악합니다. - Check Point 벤더에서 제공하는 공식 패치 또는 완화 조치 지침을 즉시 확인하고 따릅니다. - CISA의 BOD 26-04 지침에 따라 2026년 7월 25일까지 패치 또는 완화 조치를 완료합니다. - 영향받는 자산의 인터넷 노출 여부를 평가하고, 가능한 경우 외부 접근을 제한합니다. - 만약 벤더의 완화 조치가 제공되지 않거나 적용이 불가능할 경우, 제품 사용 중단을 고려합니다.

4. CVE-2026-63030 — WordPress Core Interpretation Conflict Vulnerability

  • CVSS: 9.8 CRITICAL
  • KEV 등재: 예 (등재일 2026-07-21, 패치 기한 2026-07-24)
  • 영향 제품: WordPress Core
  • 영향 버전(NVD 기준): WordPress Core 6.9 이상 6.9.5 미만 버전, WordPress Core 7.0 이상 7.0.2 미만 버전이 영향을 받습니다.
  • 랜섬웨어 연관: Unknown

개요: WordPress Core에서 해석 충돌 취약점(CVE-2026-63030)이 발견되었습니다. 이 취약점은 공격자가 SQL Injection(데이터베이스에 악성 명령어를 주입하여 데이터베이스를 조작하는 공격)을 수행하고, 궁극적으로 원격 코드 실행(시스템에서 공격자가 임의의 코드를 실행할 수 있는 공격)을 달성할 수 있도록 합니다. 이 취약점은 CVE-2026-60137과 연쇄적으로 사용될 수 있습니다.

공격 영향: 이 취약점을 악용하면 공격자는 영향을 받는 WordPress 시스템에서 데이터베이스에 접근하여 민감한 정보를 탈취하거나 변조할 수 있습니다. 더 나아가, 시스템의 제어권을 완전히 장악하여 임의의 코드를 실행할 수 있으므로, 웹사이트 변조, 악성코드 배포, 서버 리소스 오용 등 심각한 피해를 초래할 수 있습니다. 이는 시스템의 기밀성, 무결성, 가용성에 치명적인 영향을 미칩니다.

패치 우선순위: 이 취약점은 CVSS 점수 9.8점으로 매우 심각(CRITICAL)하며, CISA가 권고하는 BOD 26-04 지침에 따라 2026년 7월 24일까지 패치를 완료해야 합니다. 원격 코드 실행 및 SQL Injection의 위험성을 고려할 때, 즉시 최고 우선순위로 패치를 적용해야 합니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 현재 운영 중인 WordPress Core의 버전을 확인하고, 영향을 받는 버전에 해당한다면 즉시 최신 보안 패치로 업데이트하거나 벤더의 지침에 따라 완화 조치를 적용하십시오. - CISA의 BOD 26-04(위험 기반 보안 업데이트 우선순위 지정) 지침을 준수하여 패치 및 보안 업데이트 계획을 수립하고 이행하십시오. - CISA의 '포렌식 트리아지 요구사항'을 검토하여 잠재적인 침해 사고 발생 시 필요한 증거 수집 및 분석 절차를 준비하십시오. - 해당 WordPress 시스템이 인터넷에 노출되어 있는지 평가하고, 노출 범위에 따라 추가적인 보안 강화 조치(예: 웹 방화벽 적용, 불필요한 서비스 비활성화)를 고려하십시오. - 만약 벤더의 완화 조치가 불가능하거나 제공되지 않는 경우, CISA BOD 26-04 지침에 따라 해당 제품의 사용 중단을 고려하거나 적절한 대체 솔루션을 마련하십시오.
