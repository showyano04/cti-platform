1. CVE-2026-16812 — Arista VeloCloud Orchestrator On-Prem OS Command Injection Vulnerability

  • CVSS: 10.0 CRITICAL
  • KEV 등재: 예 (등재일 2026-07-27, 패치 기한 2026-07-30)
  • 영향 제품: Arista VeloCloud Orchestrator
  • 영향 버전(NVD 기준): Arista VeloCloud Orchestrator의 5.2.0 이상 5.2.3.14 미만 버전, 6.1.0 이상 6.1.3.4 미만 버전, 6.4.0 이상 6.4.2.4 미만 버전, 그리고 7.0.0 버전이 영향을 받습니다.
  • 랜섬웨어 연관: Unknown

개요: Arista VeloCloud Orchestrator On-Prem 제품에서 OS 명령 삽입(OS Command Injection) 취약점(CVE-2026-16812)이 발견되었습니다. 이 취약점은 원격 공격자가 악용하여 시스템의 특권 내부 기능에 접근하고 VeloCloud Orchestrator 호스트에 영향을 미칠 수 있습니다.

공격 영향: 이 취약점은 원격 공격자가 시스템에 명령을 주입하여 실행할 수 있게 함으로써, VeloCloud Orchestrator의 기밀성(정보 유출), 무결성(데이터 변조), 가용성(서비스 중단)을 모두 심각하게 침해할 수 있습니다. 공격자는 오케스트레이터가 관리하는 데이터를 포함하여 중요한 내부 시스템 기능에 접근하여 시스템 전체를 장악할 수 있습니다. 이는 CVSS v3.1 점수 10.0(CRITICAL)로 평가될 정도로 매우 심각한 보안 위험을 초래합니다.

패치 우선순위: CVSS v3.1 점수 10.0(CRITICAL)으로 매우 높은 심각도를 가집니다. CISA는 공급업체 지침에 따라 완화 조치를 적용하거나, 완화 조치가 없는 경우 제품 사용을 중단할 것을 강력히 권고하고 있으며, 2026년 7월 30일까지 패치를 적용하도록 명시되어 있으므로 최우선으로 패치해야 합니다. 랜섬웨어 연관 여부는 제공된 데이터에 명시되지 않았습니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 현재 운영 중인 Arista VeloCloud Orchestrator 제품이 있는지 확인합니다. - 운영 중인 Arista VeloCloud Orchestrator의 정확한 버전을 확인하여 위에 명시된 취약한 버전에 해당하는지 파악합니다. - 취약한 버전이 확인된 경우, Arista에서 제공하는 패치 또는 완화 조치를 즉시 적용합니다. - CISA의 BOD 26-04 지침에 따라 보안 업데이트 우선순위를 지정하고 적용해야 합니다. - 영향을 받는 Arista VeloCloud Orchestrator 자산의 인터넷 노출 여부를 평가하고, 필요한 경우 접근 제어를 강화합니다. - 만약 공급업체로부터 적절한 완화 조치가 제공되지 않는다면, CISA 권고에 따라 해당 제품 사용 중단을 고려해야 합니다.

2. CVE-2026-50522 — Microsoft SharePoint Deserialization of Untrusted Data Vulnerability

  • CVSS: 9.8 CRITICAL
  • KEV 등재: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
  • 영향 제품: Microsoft SharePoint
  • 영향 버전(NVD 기준): Microsoft SharePoint Server 버전 16.0.19725.20434 미만, Microsoft SharePoint Server 2016, Microsoft SharePoint Server 2019가 영향을 받습니다.
  • 랜섬웨어 연관: Unknown

개요: CVE-2026-50522는 Microsoft SharePoint 제품에서 발견된 역직렬화(외부에서 받은 데이터를 프로그램이 다룰 수 있는 형태로 복원하는 과정) 취약점입니다. 이 취약점을 이용하면 권한 없는 공격자가 네트워크를 통해 시스템에서 임의의 코드를 실행할 수 있습니다. CVSS 점수는 9.8점으로 심각도가 매우 높습니다.

공격 영향: 이 취약점은 권한 없는 공격자가 네트워크를 통해 악성 코드를 SharePoint 서버에서 직접 실행할 수 있게 합니다. 공격에 성공할 경우, 공격자는 서버의 제어권을 탈취하여 중요 데이터를 유출하거나 변조, 삭제할 수 있으며, 시스템 기능을 완전히 마비시키거나 다른 내부 시스템으로 추가 공격을 시도할 수도 있습니다. 이는 조직의 핵심 서비스 운영에 심각한 영향을 미칠 수 있습니다.

패치 우선순위: CVSS 점수가 9.8점(CRITICAL)으로 매우 높고, CISA에서 즉각적인 조치를 권고하고 있으므로 최우선적으로 패치를 적용해야 합니다. 랜섬웨어 연관성은 제공된 데이터에 명시되지 않았으나, 심각성을 고려할 때 조속한 대응이 필요합니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 현재 운영 중인 Microsoft SharePoint Server가 영향받는 버전에 해당하는지 즉시 확인합니다. - 영향받는 시스템이 확인될 경우, Microsoft에서 제공하는 최신 보안 업데이트를 적용하여 취약점을 해결합니다. - CISA의 BOD 26-04 지침(위험 기반 보안 업데이트 우선순위 지정)에 따라 패치 적용 및 완화 조치를 최우선으로 시행합니다. - 패치 적용이 즉시 어려운 경우, CISA 권고에 따라 제품 사용 중단을 고려하거나, 추가적인 완화 대책 마련을 위한 면밀한 검토를 수행합니다. - 패치 적용 후 시스템이 정상적으로 동작하는지 모니터링하고, 잠재적인 위협 활동에 대한 로그 분석을 강화합니다.

3. CVE-2026-16232 — Check Point SmartConsole Improper Authentication Vulnerability

  • CVSS: 9.1 CRITICAL
  • KEV 등재: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
  • 영향 제품: Check Point SmartConsole
  • 영향 버전(NVD 기준): Check Point Multi-Domain Security Management R77.30 이상 R81.20 미만 버전, R81.20 버전, R82 버전, R82.10 버전; Check Point Quantum Security Management R77.30 이상 R81.20 미만 버전, R81.20 버전, R82 버전, R82.10 버전이 영향을 받습니다.
  • 랜섬웨어 연관: Unknown

개요: CVE-2026-16232은 Check Point SmartConsole에서 발견된 부적절한 인증(시스템이 사용자의 신원을 제대로 확인하지 못하는 것) 취약점입니다. 이 취약점을 통해 인증되지 않은 원격 공격자가 애플리케이션 로그인 토큰을 탈취하여 최고 관리자 권한으로 시스템에 접근할 수 있습니다.

공격 영향: 이 취약점이 성공적으로 악용될 경우, 공격자는 별도의 인증 절차 없이 Check Point SmartConsole 시스템에 대한 완전한 관리자 권한을 획득할 수 있습니다. 이는 시스템 설정 변경, 데이터 접근 및 변조, 서비스 중단 등 심각한 보안 위협으로 이어질 수 있으며, 공격자가 조직의 보안 인프라를 완전히 통제할 가능성이 있습니다.

패치 우선순위: 이 취약점은 CVSS 9.1점으로 'CRITICAL' 등급으로 분류되며, CISA KEV(Known Exploited Vulnerabilities) 목록 등재 여부와 랜섬웨어 연관 여부는 제공된 데이터에 명시되지 않았습니다. 그러나 최고 관리자 권한 탈취 가능성이 있으므로 즉각적인 패치 적용이 필요합니다. CISA 권고에 따라 2026년 7월 25일까지 조치를 완료해야 합니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 영향받는 Check Point SmartConsole 및 관련 제품(Multi-Domain Security Management, Quantum Security Management)의 버전을 즉시 확인합니다. - Check Point 벤더의 공식 보안 권고 및 패치 정보를 확인하고, 사용 가능한 최신 보안 업데이트를 지체 없이 적용합니다. - SmartConsole에 대한 모든 관리자 로그인 시도를 면밀히 모니터링하고, 비정상적인 접근이나 의심스러운 활동이 감지될 경우 즉시 조사합니다. - Check Point SmartConsole 시스템이 불필요하게 외부 네트워크에 노출되어 있는지 확인하고, 필요한 경우 방화벽 규칙 강화, VPN 사용 등 접근 통제 정책을 엄격하게 적용합니다. - CISA의 BOD 26-04 지침에 따라 보안 업데이트 우선순위를 지정하고, 제시된 패치 기한(2026년 7월 25일) 내에 모든 권고 조치를 완료합니다. - 잠재적인 침해에 대비하여 CISA의 'Forensics Triage Requirements'에 따라 시스템 로그 및 관련 데이터의 수집, 보관 계획을 수립하고 점검합니다.
