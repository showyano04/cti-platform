1. CVE-2026-16812 — Arista VeloCloud Orchestrator On-Prem OS Command Injection Vulnerability

  • CVSS: 10.0 CRITICAL
  • KEV 등재: 예 (등재일 2026-07-27, 패치 기한 2026-07-30)
  • 영향 제품: Arista VeloCloud Orchestrator
  • 영향 버전(NVD 기준): Arista VeloCloud Orchestrator On-Prem 버전 5.2.0 이상 5.2.3.14 미만, 6.1.0 이상 6.1.3.4 미만, 6.4.0 이상 6.4.2.4 미만, 그리고 7.0.0 버전이 이 취약점에 영향을 받습니다.
  • 랜섬웨어 연관: Unknown

개요: Arista VeloCloud Orchestrator On-Prem 제품에서 OS 명령 삽입(OS Command Injection) 취약점(CVE-2026-16812)이 발견되었습니다. 이 취약점은 원격 공격자가 시스템에 명령을 삽입하여 실행할 수 있도록 허용하며, 이를 통해 권한 있는 내부 기능에 접근하고 VeloCloud Orchestrator(VCO) 호스트에 영향을 미칠 수 있습니다.

공격 영향: 공격에 성공하면 공격자는 VeloCloud Orchestrator 및 해당 Orchestrator가 관리하는 데이터의 기밀성(Confidentiality), 무결성(Integrity), 가용성(Availability)을 침해할 수 있습니다. 이는 민감 정보 유출, 데이터 변조 또는 시스템 서비스 중단으로 이어질 수 있습니다.

패치 우선순위: CVSS v3.1 점수 10.0(CRITICAL)으로 매우 높으며, CISA에서 권고 조치를 발표하고 2026년 7월 30일까지 패치 기한을 지정했습니다. 랜섬웨어 연관성은 제공된 데이터에 명시되지 않았으나, 이러한 요인들을 고려할 때 즉각적인 패치 적용 및 완화 조치가 필요한 최우선 보안 위협으로 분류됩니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 운영 중인 Arista VeloCloud Orchestrator On-Prem 제품의 버전을 확인하고, 영향을 받는 버전에 해당하는지 파악합니다. - 제공된 벤더 지침에 따라 최신 보안 패치를 적용하거나 권고되는 완화 조치를 즉시 수행합니다. - CISA의 BOD 26-04(위험 기반 보안 업데이트 우선순위 지정) 지침 및 CISA의 '포렌식 분류 요구 사항'을 준수하여 조치합니다. - 해당 제품이 클라우드 서비스인 경우, BOD 26-04 지침을 따르거나, 완화 조치가 불가능하면 제품 사용을 중단하는 것을 고려합니다. - 영향받는 시스템에 대해 비정상적인 접근 시도, 권한 상승, 또는 서비스 중단과 같은 의심스러운 활동이 있는지 지속적으로 모니터링합니다.

2. CVE-2026-50522 — Microsoft SharePoint Deserialization of Untrusted Data Vulnerability

  • CVSS: 9.8 CRITICAL
  • KEV 등재: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
  • 영향 제품: Microsoft SharePoint
  • 영향 버전(NVD 기준): Microsoft SharePoint Server 버전 16.0.19725.20434 미만, Microsoft SharePoint Server 2016, Microsoft SharePoint Server 2019 버전이 영향을 받습니다.
  • 랜섬웨어 연관: Unknown

개요: Microsoft SharePoint 제품에서 신뢰할 수 없는 데이터 역직렬화(외부에서 받은 데이터를 프로그램이 다룰 수 있는 형태로 복원하는 과정) 취약점(CVE-2026-50522)이 발견되었습니다. 이 취약점을 이용하면 권한 없는 공격자가 네트워크를 통해 원격으로 코드를 실행할 수 있습니다.

공격 영향: 이 취약점은 권한 없는 공격자가 악성 데이터를 서버에 전송하고, SharePoint 서버가 이 데이터를 처리(역직렬화)하는 과정에서 해당 데이터에 포함된 악성 코드를 실행하도록 할 수 있습니다. 공격이 성공하면 공격자는 SharePoint 서버에서 임의의 코드를 원격으로 실행하여 서버에 대한 완전한 제어권을 획득할 수 있습니다. 이는 시스템 접근 권한 탈취, 민감 정보 유출, 서비스 중단 등 심각한 결과를 초래할 수 있습니다.

패치 우선순위: CVSS 점수가 9.8점으로 매우 심각(CRITICAL)하며, 시스템에 대한 원격 코드 실행(RCE)이 가능하므로 즉시 패치 및 완화 조치 적용이 필요합니다. KEV 등재 여부 및 랜섬웨어 연관 여부는 제공된 데이터에 명시되지 않았으나, 높은 CVSS 점수만으로도 최우선 보안 조치가 필요합니다. 패치 기한은 2026년 7월 25일입니다.

  • 영향 버전(NVD 기준): 영향받는 제품 및 버전은 다음과 같습니다: Check Point Multi-Domain Security Management의 R77.30 버전 이상 R81.20 미만, R81.20, R82, R82.10 버전; Check Point Quantum Security Management의 R77.30 버전 이상 R81.20 미만, R81.20, R82, R82.10 버전입니다. 특정 버전 정보는 제공된 데이터에 명시되지 않았습니다.

4. CVE-2026-63030 — WordPress Core Interpretation Conflict Vulnerability

  • CVSS: 9.8 CRITICAL
  • KEV 등재: 예 (등재일 2026-07-21, 패치 기한 2026-07-24)
  • 영향 제품: WordPress Core
  • 영향 버전(NVD 기준): WordPress Core 6.9.0 이상 6.9.5 미만 버전; WordPress Core 7.0.0 이상 7.0.2 미만 버전
  • 랜섬웨어 연관: Unknown

개요: WordPress Core에서 발견된 해석 충돌(Interpretation Conflict) 취약점(CVE-2026-63030)은 공격자가 SQL Injection(데이터베이스에 악의적인 쿼리를 삽입하는 공격)을 수행하고, 이를 통해 원격 코드 실행(시스템에서 임의의 코드를 실행하는 능력)까지 이어질 수 있는 심각한 보안 문제입니다. 이 취약점은 CVE-2026-60137과 연쇄적으로 공격될 수 있습니다.

공격 영향: 이 취약점을 악용하면 공격자가 SQL Injection을 통해 데이터베이스의 민감 정보를 탈취하거나 조작할 수 있습니다. 더 나아가 원격 코드 실행(공격자가 영향을 받는 시스템에서 원하는 프로그램을 실행하거나 명령을 내릴 수 있는 능력)이 가능해지므로, 시스템을 완전히 장악하거나 악성코드를 배포하는 등 심각한 피해를 초래할 수 있습니다. 이는 시스템의 기밀성, 무결성, 가용성에 치명적인 영향을 미칠 수 있습니다.

패치 우선순위: CVSS 점수가 9.8점으로 '심각(CRITICAL)' 수준이며, CISA가 '위험 기반 보안 업데이트 우선순위 지정(BOD 26-04)' 지침 준수를 권고하고 패치 기한을 2026년 7월 24일로 명시했으므로 즉각적인 패치가 필요합니다. 랜섬웨어 연관성은 현재 제공된 데이터에 명시되지 않았습니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 현재 운영 중인 WordPress Core의 버전을 확인하고, 영향을 받는 버전에 해당하는지 검토하십시오. - 벤더(WordPress)가 제공하는 최신 보안 업데이트 및 패치를 즉시 적용하십시오. - CISA의 BOD 26-04(위험 기반 보안 업데이트 우선순위 지정) 지침을 준수하여 완화 조치를 적용하고 패치하십시오. - CISA의 '포렌식 트리아지 요구사항'을 참고하여 잠재적 침해 발생 시 필요한 준비를 완료하십시오. - 각 WordPress 설치 환경의 인터넷 노출 여부를 평가하고, 높은 노출도를 가진 시스템에 대한 보안 강화 조치를 우선적으로 시행하십시오. - 만약 벤더 지침에 따른 완화 조치나 패치가 제공되지 않거나 적용이 불가능할 경우, 해당 WordPress 제품의 사용 중단을 고려하십시오.
