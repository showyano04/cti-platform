주간 주요 취약점(CVE) 분석 리포트 — 2026-08-04

1. CVE-2026-16812 — Arista VeloCloud Orchestrator On-Prem OS Command Injection Vulnerability

  • CVSS: 10.0 CRITICAL
  • KEV 등재: 예 (등재일 2026-07-27, 패치 기한 2026-07-30)
  • 영향 제품: Arista VeloCloud Orchestrator
  • 영향 버전(NVD 기준): Arista VeloCloud Orchestrator 제품의 다음과 같은 버전이 영향을 받습니다: 버전 정보 없음 5.2.0 이상 5.2.3.14 미만; 버전 정보 없음 6.1.0 이상 6.1.3.4 미만; 버전 정보 없음 6.4.0 이상 6.4.2.4 미만; 7.0.0.
  • 랜섬웨어 연관: Unknown

개요: CVE-2026-16812는 Arista VeloCloud Orchestrator On-Prem 제품에서 발견된 OS 명령 삽입(운영 체제 명령을 악의적으로 주입하는 공격 기법) 취약점입니다. 이 취약점을 통해 원격 공격자가 권한 있는 내부 기능에 접근하여 VCO 호스트에 영향을 미칠 수 있습니다.

공격 영향: 이 취약점이 성공적으로 악용될 경우, 원격 공격자는 시스템에 운영 체제 명령을 주입하여 Arista VeloCloud Orchestrator 호스트의 권한 있는 내부 기능에 접근할 수 있습니다. 이는 오케스트레이터 및 오케스트레이터가 관리하는 데이터의 기밀성(민감 정보 유출), 무결성(데이터 변조), 가용성(서비스 중단)을 심각하게 손상시킬 수 있습니다. 공격자는 시스템 명령을 실행하여 데이터를 유출하거나, 시스템 설정을 변경하거나, 서비스 운영을 방해하는 등의 악의적인 행위를 수행할 수 있습니다.

패치 우선순위: 이 취약점은 CVSS 점수 10.0(CRITICAL)으로 매우 심각한 수준입니다. CISA는 해당 취약점을 중요한 보안 업데이트로 분류하고 2026년 7월 30일까지 패치 적용을 권고하며, CISA BOD 26-04 지침을 준수하도록 명시했습니다. KEV(Known Exploited Vulnerabilities) 카탈로그 등재 여부 및 랜섬웨어 연관성은 제공된 데이터에 명시되지 않았으나, 최고 수준의 CVSS 점수와 CISA의 긴급 권고에 따라 즉각적인 패치 적용 및 완화 조치가 필요합니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 현재 사용 중인 Arista VeloCloud Orchestrator의 버전을 확인합니다. - 영향받는 버전에 해당하는 경우, 즉시 제조사(Arista)의 권고 사항 및 패치를 적용합니다. - CISA BOD 26-04 지침에 따라 위험 기반 보안 업데이트 우선순위를 설정하고 이행합니다. - 해당 제품의 인터넷 노출 여부를 평가하고, 필요한 경우 접근 제어를 강화하여 공격 표면을 줄입니다. - 패치가 불가능하거나 제공되지 않는 경우, 해당 제품의 사용 중단을 고려하거나 대체 솔루션을 검토합니다. - CISA의 '포렌식 트리아지 요구사항'을 준수하여 잠재적 침해 상황에 대비하고 필요한 로그를 확보합니다.

2. CVE-2026-50522 — Microsoft SharePoint Deserialization of Untrusted Data Vulnerability

  • CVSS: 9.8 CRITICAL
  • KEV 등재: 예 (등재일 2026-07-22, 패치 기한 2026-07-25)
  • 영향 제품: Microsoft SharePoint
  • 영향 버전(NVD 기준): Microsoft SharePoint Server 버전 16.0.19725.20434 미만; Microsoft SharePoint Server 2016; Microsoft SharePoint Server 2019
  • 랜섬웨어 연관: Unknown

개요: Microsoft SharePoint에서 신뢰할 수 없는 데이터 역직렬화(외부에서 받은 데이터를 프로그램이 다룰 수 있는 형태로 복원하는 과정) 취약점(CVE-2026-50522)이 발견되었습니다. 이 취약점은 권한 없는 공격자가 네트워크를 통해 코드를 실행할 수 있도록 허용합니다.

공격 영향: 이 취약점은 권한 없는 공격자가 네트워크를 통해 SharePoint 서버에 임의의 코드를 실행할 수 있게 합니다. 공격에 성공할 경우, 공격자는 서버를 완전히 제어하거나, 악성 프로그램을 설치하거나, 중요한 데이터를 탈취 또는 변조하는 등 시스템에 심각한 피해를 줄 수 있습니다. 이는 전사적 데이터 유출, 서비스 중단, 또는 추가적인 내부 시스템 침해로 이어질 수 있습니다.

패치 우선순위: CVSS 점수 9.8점으로 심각(CRITICAL)하며, 권한 없는 원격 코드 실행이 가능한 점을 고려할 때 즉시 패치를 적용해야 합니다. CISA KEV에는 등재되지 않았으며, 랜섬웨어 연관성은 현재 알 수 없습니다. CISA에서 2026년 7월 25일까지 패치 기한을 권고하였으나, 심각성을 고려하여 기한보다 빠르게 조치해야 합니다.

공식 패치·완화조치(CISA 권고): Apply mitigations in accordance with vendor instructions, ensuring compliance with CISA’s BOD 26-04 Prioritizing Security Updates Based on Risk (see URL in Notes) guidance and CISA’s “Forensics Triage Requirements” (see URL in Notes). Follow applicable BOD 26-04 guidance for cloud services or discontinue use of the product if mitigations are unavailable. Stakeholders are responsible for evaluating each asset's internet exposure and ensuring adherence to BOD 26-04 patching guidelines.

운영자 확인 사항: - 해당하는 모든 Microsoft SharePoint 서버에 대해 벤더(공급업체)가 제공하는 최신 보안 업데이트 및 패치를 즉시 적용합니다. - SharePoint 서버에 대한 외부 네트워크 접근 제어 정책을 검토하고, 불필요한 포트 개방이나 서비스 노출을 최소화하여 공격 가능 범위를 줄입니다. - CISA BOD 26-04 지침에 따라 SharePoint 서버의 인터넷 노출을 평가하고, 위험 기반 패치 지침을 철저히 준수합니다. - 만약 패치 또는 적절한 완화 조치가 불가능하다면, 해당 SharePoint 제품의 사용 중단을 심각하게 고려해야 합니다. - 향후 발생할 수 있는 잠재적 침해 사고에 대비하여 CISA의 'Forensics Triage Requirements'를 참고하여 포렌식 대비 계획을 검토하고 준비합니다.

참고 자료: - https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-50522 - https://www.cisa.gov/news-events/directives/bod-26-04-prioritizing-security-updates-based-risk - https://www.cisa.gov/news-events/directives/bod-26-04-implementation-guidance-prioritizing-security-updates-based-risk - https://nvd.nist.gov/vuln/detail/CVE-2026-50522
